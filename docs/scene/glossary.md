## 1. Business Terms

| 中文名 | 统一标识 | 解释 | 易混淆的边界 |
| --- | --- | --- | --- |
| 房间 / 组合 | combo（scene × preset） | 一个场景×预设的固定搭配，是绑定会话与记忆的所有权单位 | 房间不是预设（人是身份），不是模式（全局开关），也不是页面（页面只是常见的门） |
| 预设 | preset | 「这个人是谁」：人格声明与记忆上层的主体 | 人格走声明，事实记忆走上层人级记忆；预设不随房间切换而变 |
| 绑定行 | binding | 组合→专属会话的对应记录；一间房一条 | 不是页面绑定（那是任务语义：重开即新建）；房间语义是再进即恢复 |
| 进入 | enter | 激活某房间：首次创建其专属会话，之后恢复 | 即时生效（就是打开对应会话），无排队等待 |
| 建议 | suggestion | 自动判定产出的「要去这间吗」提示，默认不自动进门 | 建议不是切换；显式进入才是切换 |
| 迟滞 | hysteresis | 自动信号须连续命中多次才产出建议的防抖门 | 显式请求不过迟滞门 |
| 记忆阶梯 | memory ladder | 五层记忆：临时（会话）、工作（工作区）、场景（组合）、个人（预设）、世界（无主体） | 读取全阶梯可见；兄弟房间的原始记忆互不可见是唯一例外 |
| 临时记忆 | temp memory | L0，会话内的情节与未沉淀事实 | 随会话而灭，上行的只有提炼条目 |
| 工作记忆 | working memory | L1，工作区级的项目沉淀（决定、约定、坑） | 工作区的组织元数据仍对模型不可见，可见的是项目知识 |
| 场景记忆 | scene memory | L2，房间沉淀，作用域为组合 | 兄弟房间互不可见；上行的只有提炼条目 |
| 个人记忆 | personal memory | L3，随预设共享的人级事实与偏好 | 不承载人格（人格是声明不是记忆） |
| 世界记忆 | world memory | L4，无主体的通用知识 | 跨人可见，写入必须过治理门 |
| 晋升 | promotion | 记忆从低层向高层的上行流动 | 只上行不下行；判据是重复 |
| 蒸馏器 | distiller | 异步维护任务：判断重复、提炼条目、写入上一层 | 阈值（N 次/M 单元）是配置；L3→L4 被治理门拦住 |
| 治理门 | governance gate | 跨主体晋升（个人→世界）的审核关卡 | 默认禁自动；显式晋升也要留审核记录 |
| 统一记忆工具面 | unified memory tool face | 记忆只有 recall（读全阶梯）与 write（只写 L0）两个操作，五层共用 | 高层无写入口是接口形状决定的，不是检查决定的；L1–L4 全部来自晋升 |
| 每日整理任务 | daily distillation job | 每日定时批处理：回顾当天历史会话，触发 L0→L4 整理晋升 | 隔夜冷却与水位保证幂等；L4 候选只进审核队列 |
| 隔夜冷却 | overnight cooldown | 本轮新晋升的条目次日才参与上一级蒸馏 | 防止一条事实一夜连跳四层 |
| 水位 | watermark | 每层记录的处理进度线：`[上次成功, 本次触发)` | 同窗口重跑幂等的凭据 |
| 显式晋升 | explicit promotion | 人工覆盖通道：越过重复判据直接晋升 | 留 `promotedBy: explicit` 记录；L4 仍须治理门 |
| 解绑 | unbind | 拆除绑定行并清除房间专有记忆（破坏性，须确认） | 会话本体保留在会话列表，删的是房间记忆不是对话数据 |
| 重建 | rebuild | 绑定行指向的会话被外部删除后，显式新建并注明 | 与恢复不同：旧上下文不可恢复是如实结果 |

## 2. Technical Terms

| 术语 | 解释 | 在本方案中的用途 |
| --- | --- | --- |
| 会话作用域装配 | 会话创建时按其所属组合一次性装配工具、技能与人格段落，声明自此不变 | 「会话面冻结」铁律的实现位 |
| 绑定行模式 | 「键 → 会话」的对应记录与存储域（宿主应用页面已实践同款） | 组合→会话绑定的实现基础 |
| 拦截式征询 | 按序征询监听者，第一个拍板的结论生效并短路 | 自动判定钩子的征询模式 |
| 前缀缓存 | 模型服务按请求开头内容命中的计费缓存 | 房间模型的设计依据：每会话前缀冻结，切换零缓存代价（见[总体方案](./architecture/)第 6 节） |
| 长对话压缩 | 旧对话片段折叠成摘要以腾出空间 | 摘要随会话归属，是房间专有记忆的一部分 |
| 无人值守契约 | 会话在后台继续完成在途回合的宿主既有机制 | 切走房间后在途回合不打断的实现位 |
| fail-loud | 配置或数据错误当场拒绝，不带病运行 | 登记校验与绑定行损坏的原则 |
| 记忆作用域 | 记忆的归属键：临时用会话、工作用工作区、场景用组合、个人用预设、世界无键 | 记忆阶梯隔离的结构基础 |
