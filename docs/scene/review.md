## 4. Core Domain Verdicts

- **Resolver（核心，存疑记录）**：① 主链不可缺——没有它自动场景不存在；② 「乱建议即失格」依赖「场合感是产品承诺」的判断，属存疑项：建议制下乱建议的代价已被降到最低（用户可忽略），若评审认为建议无需核心化，Resolver 退为外围。两读均改变核心比例（2/5=0.4 或 1/5=0.2），都在可接受区间，待评审拍板。
- **Recall（核心）**：① 主链不可缺——记忆串房即产品失信；② 失守即失格——兄弟房间泄漏是隐私事故。简证成立，无需过滤引擎的结构隔离是其关键设计决策。
- **比例核对**：核心 2 ÷ 总数 5 = 0.4，区间上缘；外围三模块（Registry/Binder/Indicator）按「外围定位声明 + 从简验收」处理，Binder 另有绑定行复用依据（宿主页面绑定先例），未静默减配。
