## 1. 用户三轮裁定与落地

1. **「全部是画布，没有编辑」** → 画布模式全幅，常驻编辑器栏移除；选中卡的编辑器+链接两段改为画布左上浮动检查器（× 关闭）。
2. **「节点关系用节点和边表示」** → 边线不可见根因为 SVG 0×0 视口裁剪，改为显式 width/height + translate 组后 8 条边全部可见；加宽墨线 1.8px。
3. **「不要留白」** → 页头/布局/横幅三处 1120px 限宽移除，全幅铺满。

## 2. 装配配方（本次沉淀）

- 同版本 file: tarball 重复安装 pnpm 不重解（added 0）——**必须删成员目录再 add**；版本号规范（先 bump 再发布）正是为 registry 形态准备的，本地 tarball 迭代靠重装。
- repack.mjs 两处修复：家族前缀歧义（`veren-notebook-` 撞 `-app/-ui`）→ 先精确 `名-版本` 匹配；`pnpm pack` 把成员 `workspace:^` 改写为 semver 区间而未发布的 rc 无处解析 → 成员 tarball 的兄弟依赖也改写为 file:。
- 3080 端口僵尸：`netstat LISTENING` 的 PID 可能不是真监听者（多次误杀）；以 `grep ":3080 "` 全状态行交叉确认，杀后**轮询到 LISTENING/ESTABLISHED/FIN_WAIT 全清**再启动（~35s）。
- IAB 窗格被遮挡时：rAF=0、ResizeObserver 冻结、PointerEvent 命中测试失效——一切帧依赖的交互验证在此期间**不可信**；DOM click 派发（el.click）不受影响，可用于 wiring 验证。

## 3. 缺陷与修复账

| 缺陷 | 修复 |
|---|---|
| × 关闭被「自动选中第一条」跟随效应顶回 | everSelected 闸：每盒只自动选中一次，显式清除后保持清除；换归属重置 |
| 边点击无响应（pointerdown 即 setPointerCapture，click 被重定向到舞台） | 阈值后才捕获：4px 内是纯点击（落到真目标），越阈才接管手势；空白点击改走舞台 onClick |
| SVG 0×0 视口 + overflow 依赖在真机被裁剪 | 显式 width/height 覆盖图幅 + translate 组 |
