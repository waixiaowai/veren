## 27. Page Components

页面是薄封装：从路由里取参数，按视图把 [第 26 章](./business/) 的业务组件摆好，再处理本页独有的交互（切月、切标签、开浮层、恢复滚动位置）。它不重复业务请求逻辑，也不自己拼接口。当前四个壳的导航状态都在内存里，没有路由；本章先按目标形态写清哪些状态该进 URL，再把现状与差异标出来。

### 27.1 Layer Rules

| 允许 | 禁止 |
| --- | --- |
| 读取与校验路由参数，非法值回退到默认 | 在页面里直接发请求或拼查询串 |
| 组装业务组件，决定同屏显示哪几块 | 复制业务组件已有的加载与失败分支 |
| 处理页面级交互：切月、切标签、开合浮层、恢复滚动 | 持有跨页共享的实体缓存 |
| 管理页面级状态：选中项、搜索词、分页 | 把服务端事实写进页面局部状态再回写 |
| 决定本页四态的呈现与默认动作 | 用整页空白表示无权限或失败 |

判定方法很简单：把页面里的一段逻辑搬到另一个页面仍然成立，它就属于业务组件；只在这个页面成立（例如“切到上个月”），才留在页面层。

页面之间不互相嵌套。一个页面只在导航层被选中一次，浮层与右槽都挂在当前页面之下，而不是另一个页面；这样后退时只需要还原导航状态，不必回放整棵页面树。页面也不持有跨页缓存，切换视图时业务组件按自己的规则取数或命中缓存。

### 27.3 State in URL

可分享、可恢复的状态进 URL；不能见光或不需要分享的留在本机。当前实现没有路由，下表是目标形态。

| 参数 | 类型 | 默认值 | 非法值处理 | 写入方式 |
| --- | --- | --- | --- | --- |
| view | 十个视图的枚举 | conversations | 回退 conversations 并 replace | 切换主导航用 push |
| conversation | 会话 id | 空 | 不存在则清空并用 replace，展示空态 | 选中会话用 push |
| filter | all，unread，agents，humans，groups，email，whispers，project 加项目 id | all | 回退 all | 切筛选用 push，并把 page 归 1 |
| q | 字符串，最长 80 | 空 | 超长截断 | 输入防抖 300ms 后 replace |
| thread，info | 消息 id，成员 id | 空 | 不存在则关闭对应槽并 replace | 打开浮层用 push |
| doc，board，card，event | 实体 id | 空 | 不存在则清空并显示不可用 | 打开浮层用 push，槽内切换用 replace |
| calendar | 年月，形如 2026-11 | 当前月 | 解析失败回退当前月 | 切月与回到今天用 replace |
| page，limit | 正整数，limit 取 20、50、100 | 1，50 | 越界钳制到边界 | 翻页用 push |
| tab | me 的六个标签 | profile | 回退 profile | 切标签用 push |

规则：筛选变化一律重置分页到第一页，且旧页结果整块丢弃，不做“第 3 页重新过滤”。同一实体的浮层内部切换（例如文档换文档）用 replace，避免后退时逐个关闭浮层。前进后退必须与 URL 完全一致，禁止用动画状态改写 URL。

编码约定：参数名用小写短词，多值用重复键而不是逗号拼接；缺省值不写进 URL，保持链接最短。空字符串视为未设置，与非法值一样回退默认，并在回退时用 replace 抹掉坏参数，避免坏链接被复制传播。

留在本机的状态与恢复顺序如下。

| 状态 | 存放 | 恢复优先级 | 有效期 | 清理时机 |
| --- | --- | --- | --- | --- |
| 输入草稿 | 本机存储，按会话分键，上限 50 条与 256 KiB | 最高，URL 无对应项 | 长期，按最近使用淘汰 | 发送成功，或用户手动清除 |
| 面板宽度 | 本机存储，侧栏与右槽各一键 | 仅本机，不参与 URL | 长期 | 用户重置布局 |
| 主题 | 本机存储与系统偏好 | 手动选择高于系统 | 长期 | 用户改回跟随系统 |
| 语言 | 本机存储 | 高于浏览器语言 | 长期 | 用户切换 |
| 浮层与选中 | 目标形态进 URL，当前在内存 | URL 高于内存 | 会话期 | 导航离开或刷新 |

安全约束：密码、令牌、配对码绝不进 URL。OAuth 回跳用一次性片段，消费后立即清除；邀请令牌可以进 URL，但接受成功后必须 replace 掉，避免分享链接被重复使用。

待确认事项集中在“从内存状态迁到 URL”这一段：

- 目标形态要求桌面壳把内存中的视图、选中会话、右槽与筛选映射为查询参数，Electron 需把深链转换成同一套参数。当前无路由，迁移范围与兼容期 — 待确认。
- 后台已使用真实路径与 pushState，是否并入统一路由与统一参数命名 — 待确认。
- 移动端的返回手势与系统返回键是否映射为历史后退；若映射，列表到聊天是否产生一条历史记录 — 待确认。
- 右槽当前五选一互斥，文档与看板能否与线程同时打开 — 待确认。
- 本机草稿在多设备间是否同步；当前按设备保存，跨设备不迁移 — 待确认。

### 27.4 Four States

每页四态都要有默认动作。空态必须区分“尚无数据”与“筛选无结果”，前者给创建入口，后者给清除筛选。

| 页面组 | 加载 | 空，尚无数据 | 空，筛选无结果 | 失败 | 无权限 |
| --- | --- | --- | --- | --- | --- |
| 会话 | 列表骨架，标题位保留 | 引导新建群组或发起私聊 | 清除筛选与关键词 | 保留筛选，给重试 | 不适用，成员即可见 |
| 旁听 | 列表骨架 | 说明尚无智能体互聊 | 无筛选 | 重试，返回会话 | 说明仅所有者可见，给返回 |
| 站立会 | 宫格占位 | 说明没有进行中的会，给开始 | 无筛选 | 重试，保留已结束稿 | 不适用 |
| 名册 | 卡片骨架 | 给添加智能体入口 | 无筛选 | 重试，保留筛选 | 编辑与离队按角色禁用并说明 |
| 看板 | 画布骨架 | 给建看板与建卡入口 | 无筛选 | 保留看板与列，重试卡片 | 只读看板需明示原因 |
| 日程 | 月网格占位 | 给新建事件入口 | 无筛选 | 重试，保留当前月 | 私密事件不显示，不提示无权 |
| 文档 | 列表与编辑器骨架 | 给新建文档入口 | 无筛选 | 编辑器保留本地增量，重试同步 | 说明打开权限，给申请入口 |
| 交付 | 主从骨架 | 给建功能入口 | 无筛选 | 重试，保留选中 | 只读态说明 |
| 观测 | 运行表占位 | 说明尚无运行记录 | 清除筛选 | 重试 | 能力未开时说明并给申请，不静默跳走 |
| 我 | 分区骨架 | 各分区独立空态 | 无筛选 | 分区重试 | 仅所有者可见项隐藏并说明 |
| 移动列表 | 行骨架 | 与桌面同文案 | 清除搜索 | 下拉重试 | 与桌面一致 |
| 认证与引导 | 按钮转圈 | 不适用 | 不适用 | 行内错误与重试 | 不适用 |
| 后台列表 | 表格骨架 | 说明暂无待审 | 清除查询与筛选 | 横幅加重试，保留表头与筛选 | 非管理员显示身份与退出 |

部分区块失败时按块降级，不整页清空：会话页右槽失败不影响消息流；看板的卡片加载失败保留列表与列；我的六个标签各自独立；后台表格失败保留表头与筛选控件。任何降级都必须在原位置说明，不用整页空白或整页错误页顶替。

### 27.5 Transitions

| 场景 | 转场 | 时长与曲线 | 幂等要求 |
| --- | --- | --- | --- |
| 主导航切换 | 交叉淡入，旧视图先卸载 | tab-fade 140ms，standard | 重放不重复请求，命中缓存先渲染再校验 |
| 移动推入与弹出 | 整屏位移，背景视差三成 | spring，刚度 320，阻尼 38，质量 1 | 同一目标重复推入不叠加历史 |
| 浮层开合 | 透明度加 4px 位移 | 进场 base 配 enter，出场 fast 配 leave | 后退直接关闭，不重播进场 |
| 后台列表到详情 | 直接替换并复位滚动 | 无动画 | 后退恢复原滚动位置 |
| 刷新 | 不播进场，直接落位 | 0ms | 恢复参数后重新取数，不重放动画 |

视觉位置恢复优先于进场动画：先按 URL 还原选中项、滚动锚点与展开的分组，再决定要不要播放动画。位置尚未恢复时宁可不播，也不要“先滑到顶部再跳回去”。刷新与前进后退可以重放同一段转场，但必须幂等：不改写 URL、不重复提交、不产生第二条历史记录。
