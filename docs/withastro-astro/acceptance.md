## 28. System Acceptance

验收描述**最终完成状态**，不分期、不设里程碑。每条验收都能在真实宿主中复现；"验证方式"列说明用什么手段取证（自动化测试、命令输出、浏览器观察、日志、产物检查）。性能与容量项未给出目标值的标注"待确认"，不以主观感受代替。

### 28.1 End to End Cases

| 编号 | 场景 | 前置条件 | 操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- | --- | --- |
| SYS-01 | 命令覆盖 | 空目录 + 已安装依赖 | 依次执行 `dev`/`build`/`preview`/`check`/`sync`/`add`/`info`/`telemetry`/`preferences`/`create-key`/`docs` | 每个命令都有明确结果与退出码；未知命令回落帮助 | 命令矩阵截图 + 退出码断言 |
| SYS-02 | 配置失败可读 | 配置文件含类型错误 | `astro build` | 退出码 1；错误指出文件、字段、期望值；无未捕获栈 | 终端输出比对错误码表 |
| SYS-03 | 路由优先级 | 静态页与动态页共存 | 请求两者路径 | 静态优先、动态兜底；顺序在两次构建中一致 | 请求断言 + 路由表快照 |
| SYS-04 | 国际化回退 | `i18n` 配置两种回退类型 | 请求缺失语言的路径 | 重定向或重写符合配置；地址栏行为正确 | 浏览器 + `curl` 头检查 |
| SYS-05 | 岛屿水合 | 页面含三种客户端指令 | 加载页面 | 只加载声明边界的脚本；未进入视口的岛不下发脚本 | 网络面板 + DOM 断言 |
| SYS-06 | 请求管线 | 中间件、Cookie、CSP、CSRF 同页启用 | 正常请求与跨站 POST | 正常请求带 Cookie 与 CSP 头；跨站 POST 403 | 响应头断言 |
| SYS-07 | 双模式构建 | 同项目分别以 static/server 构建 | 两次 `build` | static 产出静态文件；server 产出可被适配器导入的入口 | 产物树检查 + 宿主启动 |
| SYS-08 | 增量构建 | 首次构建后仅改一页 | 再次构建 | 只重建受影响页；复用页内容与首次一致 | 构建摘要 + 文件 mtime/哈希 |
| SYS-09 | 资源优化 | 本地图与远程图、非默认字体 | 请求图片端点与页面 | 输出格式/尺寸符合参数；未授权远程图 403；字体子集化生效 | 响应头 + 图片尺寸检查 |
| SYS-10 | 内容层 | 定义两类集合，一条数据故意非法 | `sync` 与构建 | 合法条目可查询与渲染；非法条目失败并指出字段；存储不写入非法数据 | 构建日志 + 查询结果 |
| SYS-11 | 动作契约 | `accept: 'json'` 与 `'form'` 各一个动作 | 合法、缺字段、未知动作三类请求 | 200/422/404；处理函数调用次数符合预期 | 请求断言 + 服务端计数 |
| SYS-12 | 会话与缓存 | 配置会话驱动与缓存提供方 | 写入会话、命中缓存、按标签失效 | 会话跨请求保持且过期失效；缓存命中带正确头；标签失效只影响目标项 | 多请求序列断言 |
| SYS-13 | 集成顺序 | 两个集成各自在多个钩子写日志 | 构建 | 钩子按注册顺序执行；任一钩子抛错即中止并指出集成名 | 钩子日志顺序断言 |
| SYS-14 | 适配器能力 | 安装官方适配器并声明特性 | 构建 + 预览 | 不支持的组合在构建期失败或告警；支持组合可预览 | 构建输出 + `preview` 请求 |
| SYS-15 | 客户端导航 | 页面启用视图过渡与预取 | 站内跳转、预取悬停 | 不整页刷新；滚动恢复正确；预取不产生重复请求 | 浏览器观察 + 网络面板 |
| SYS-16 | 编辑器诊断 | 项目含一处类型错误 | 打开编辑器 | 诊断定位到文件行列；码与构建一致；修复后消失 | 编辑器截图 + 语言服务器日志 |
| SYS-17 | 开发服务器 | 运行中修改模板、样式、配置 | 三次保存 | 模板局部更新；样式替换；配置触发重启；失败时保留旧服务 | 浏览器 + 终端日志 |
| SYS-18 | 开发工具栏 | 页面含岛与可访问性问题 | 打开四个应用面板 | 审计列出问题并可定位；岛检查高亮；设置持久化；菜单可复制调试信息 | 浏览器操作记录 |
| SYS-19 | 权限与隔离 | 两个项目并行运行 | 交叉读取会话、缓存、锁文件 | 互不可见；越权返回 403/404；切换项目后内存状态重建 | 双实例实验 + 存储检查 |
| SYS-20 | 诊断与遥测 | 开启遥测、触发一次失败 | 查看遥测与 `info` | 只上报匿名计数与错误码；`info` 不含机密；可关闭遥测 | 遥测载荷检查 |

### 28.2 Special Checks

| 类别 | 要求 | 验收方式 |
| --- | --- | --- |
| 权限 | 至少覆盖：越权拒绝、跨主体不可见、切换主体后状态失效 | SYS-19 + A-18-01…A-18-06 |
| 状态 | 至少覆盖：一次非法转移被拒绝且返回对应码 | A-20-01…A-20-06 + 各状态图非法转移表 |
| 界面四态 | 每个浏览器页面与终端页面都给出加载、空、失败、无权限；空态区分"无数据/筛选无结果"；失败态可重试并保持筛选 | 27 章逐页检查 + A-22-01…A-22-06 |
| 键盘可达 | 工具栏、面板、覆盖层可仅用键盘完成打开、切换、关闭；焦点可见 | A-23-05、原型实测 |
| 国际化布局 | zh-CN 与 en 下文案不溢出、不截断关键信息；目标语言切换后布局不跳动 | A-23-06、A-24-02 |
| 离线可读 | 阅读页断网可打开；图为本地 SVG；无外部字体与脚本 | 断网打开 `web/index.html` |

### 28.4 Gaps

| 项 | 原因 | 处理 |
| --- | --- | --- |
| 托管平台的 CDN 缓存行为 | 属适配器与平台方职责，框架只输出头 | 在适配器文档中单独验收，不纳入本表 |
| 站点作者自己的页面设计 | 属产物侧业务，不在框架产品端内 | 由站点项目的设计文档覆盖 |
| 多租户 SaaS 能力 | 框架不提供账号与租户模型 | 明确排除；如需，由应用层实现并在 18 章补充主体 |

### 28.5 Traceability Check

1. 20 条需求全部有实现归属、有验收项，无孤立需求。
2. 20 条验收全部回指至少一条需求，无孤立验收。
3. `N-19`/`SYS-19` 的行同时引用权限矩阵与隔离规则，不重复粘贴模块验收。
4. 无法对应的三项已就地说明原因，不静默省略。
