## 18. Permissions

框架没有登录系统，但**有主体**：数据归属与权限判定的单位。本方案的判定单位是"一次运行所服务的项目"——项目根目录、它的机密变量、它的会话命名空间、它的构建产物都属于该项目；访客、集成、适配器与宿主围绕它获得受限能力。所有接口、页面与组件的能力描述以本节的矩阵为唯一来源，同一能力不得在别处写成相反结论。

### 18.1 Subjects

| 主体 | 定义 | 归属数据 | 是否可切换 | 默认主体 |
| --- | --- | --- | --- | --- |
| `project` | 一次命令（dev/build/sync）所绑定的项目根 | 源码、配置、内容存储、构建缓存、会话命名空间、产物 | 否（切换等于换一次运行） | 是（缺省 = 进程 cwd 所在项目） |
| `visitor` | 发出 HTTP 请求的匿名访问者 | 会话记录、动作调用产生的业务数据 | 否 | 每次请求新建 |
| `integration` | 通过钩子参与构建的第三方包 | 其自身注入的路由、脚本、中间件、工具栏应用 | 否 | 按注册顺序 |
| `adapter` | 部署形态的运行时代码 | 服务入口、清单读取权、部署平台配置 | 否 | 唯一（`setAdapter` 只允许一次） |
| `host` | 承载请求的宿主进程（Node 服务器、Serverless、Edge） | 请求与响应、进程级状态 | 否 | 唯一 |

主体之间的三个硬边界：

1. **`project` 边界不可跨越**：任何模块只能访问当前项目根内的文件；跨项目读取（如 `../other-app/.env`）一律拒绝。
2. **`integration` 只扩展、不裁定**：可以注入、可以改打包配置，但不能改写路由排序结果，也不能读取机密变量的值（只能声明需要，由宿主注入）。
3. **`visitor` 只见客户端可见面**：服务端变量、源码、清单、栈永远不进入发往浏览器的响应；开发期通道不向非本机来源开放。

### 18.2 Resources and Actions

| 资源 | 说明 | 关键字段（判定依据） |
| --- | --- | --- |
| `R1 项目文件` | 源码、内容、配置、公开目录 | `root`、`srcDir`、`publicDir` |
| `R2 机密变量` | `context: 'server'` 且 `access: 'secret'` 的环境变量 | `env.schema[name]`、运行上下文 |
| `R3 公开变量` | `access: 'public'` 的环境变量 | 前缀规则、`context` |
| `R4 客户端产物` | 进入浏览器的 HTML、脚本、样式 | 是否被 `client:*` 引用、是否含服务端导入 |
| `R5 会话数据` | `ctx.session` 中的键值 | 会话 ID、`ttl`、cookie 属性 |
| `R6 缓存命名空间` | 缓存提供方的键空间与标签 | `routeRules`、`tags`、`base` |
| `R7 开发期通道` | 工具栏与热更新 WebSocket | 请求来源、是否开发模式 |
| `R8 动作入口` | `/_actions/*` 可达性 | `output`、动作是否注册、`accept` |
| `R9 产物目录` | `outDir` 下的文件 | 构建阶段、是否首次写入 |

### 18.3 Permission Matrix

判定只取**允许**、**拒绝**、**条件**；"条件"必须写明依据字段。

| 角色 | 资源 | 操作 | 判定 | 条件依据 |
| --- | --- | --- | --- | --- |
| `project` | R1 | 读取与写入项目内文件 | 允许 | 路径必须落在 `root` 内，且不跨越符号链接指向外部（待确认：符号链接策略） |
| `project` | R1 | 读取项目外文件 | 拒绝 | — |
| `project` | R2 | 在服务端读取机密值 | 允许 | 仅构建进程与服务端运行时代码 |
| `project` | R3 | 在客户端读取公开值 | 允许 | `context: 'client'` 且前缀合法 |
| `integration` | R2 | 读取机密值 | 拒绝 | 集成只能声明依赖，值由宿主注入 |
| `integration` | R1 | 通过钩子读取配置与路由 | 允许 | 只读快照；写入需走 `updateConfig` |
| `integration` | R1 | 直接改写路由排序 | 拒绝 | 路由裁定权归 `routing` |
| `integration` | R7 | 注册工具栏应用与事件 | 允许 | 仅开发模式；事件名必须带应用前缀 |
| `adapter` | R9 | 写入产物目录外的路径 | 拒绝 | 只能写 `outDir` 与其子目录 |
| `adapter` | R4 | 读取客户端资源清单 | 允许 | 通过 `SSRManifest` 只读访问 |
| `visitor` | R8 | 调用已注册动作 | 条件 | `output === 'server'` 且动作存在且输入通过校验 |
| `visitor` | R5 | 读写自己的会话 | 条件 | 会话 cookie 有效且未过期；跨会话 ID 一律拒绝 |
| `visitor` | R4 | 获取服务端堆栈或源码 | 拒绝 | 生产期错误页不含栈；开发期仅本机可见 |
| `host` | R6 | 失效全部缓存 | 条件 | 必须提供 `tags` 或 `path`，禁止无参全量失效 |
| `visitor` | R7 | 访问开发期通道 | 拒绝 | 非开发模式或非本机来源 |

矩阵的三条推论：页面渲染与接口调用的权限判定必须同时满足"资源可达"与"主体匹配"；同一失败无论发生在页面还是接口都返回统一语义（越权 403、资源不存在 404、未认证不单独暴露）；组件层面的"不可见"必须在服务端决定，不能靠前端隐藏。

### 18.4 Data Isolation

**查询范围**：内容查询默认只落在当前项目的内容存储；会话读取只按当前 cookie 的会话 ID；缓存键统一带 `base` 与项目标识前缀，避免多站点共享提供方时串键。

**越权失败码**：统一使用 `403`（有权限判定但被拒）与 `404`（资源不存在或不允许暴露存在性）；不得用 200 + 空数据掩盖拒绝。

**主体切换后的失效**：框架内唯一的"切换"是换项目或换请求。换项目时，设定快照、路由表、编译缓存、内容存储、锁文件全部重建，不继承上一个项目的内存状态；换请求时，`locals`、`cookies`、`session`、`cache` 句柄、CSP 收集器全部重新创建，`RenderContext` 不得跨请求复用。

**跨主体聚合**：列表与统计只统计当前项目的数据；遥测只上报匿名计数与错误码，不上报路径、内容或环境变量值。**构建缓存隔离**：缓存键含设定指纹与项目根哈希，两个项目即使共用 `cacheDir` 也不会互相复用页面产物。

### 18.5 Acceptance

| 编号 | 前置条件 | 操作 | 可观察结果 |
| --- | --- | --- | --- |
| A-18-01 | 项目 A 运行中 | 在项目 B 目录执行 `astro dev` | 两个实例互不复用锁文件、缓存、会话命名空间；端口冲突按规则处理 |
| A-18-02 | 页面尝试读取 `../` 之外的配置 | 构建 | 访问被拒绝并给出结构化错误，不泄露外部文件内容 |
| A-18-03 | 机密变量 | 在客户端组件中引用 | 构建失败或运行期报 `EnvPrefixConflictsWithSecret`，值不进入客户端产物 |
| A-18-04 | 已登录访客 A 的会话 cookie | 用其会话 ID 构造访客 B 的请求 | 拒绝，返回 403/404，不返回 A 的数据 |
| A-18-05 | 生产构建 | 访问 `/_actions/unknown` | 404，响应体不含动作清单 |
| A-18-06 | 任意构建 | 检查客户端脚本 | 不含服务端模块路径、环境变量或清单内容 |
