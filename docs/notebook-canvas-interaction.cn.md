# notebook 画布交互规格 + spike 报告

> 状态：**已实现，随 4.0.0-rc.3 交付**。任务书：docs/notebook-canvas-expiry-task.cn.md（D 系列裁定在其 §3）。
> **真机用户裁定（2026-11-03）**：①「全部是画布，没有编辑」——画布模式全幅，常驻编辑器栏移除，列表模式保留为索引/无障碍等价面；②「节点关系用节点和边表示」——边线必须可见；③「不要留白」——去掉全部限宽，面板满幅；④**「技术栈错误：不许用绝对定位 DOM 卡片，要用专业的 canvas 库」**——渲染层由绝对定位 DOM 换成 Konva（Canvas2D 场景图），见 §7。
> 真机验收数字见 docs/acceptance/notebook-4.0.0-rc.2/ 的 rc.2 报告；rc.3 的渲染层验收依据是包内单测 + 真实 Chrome 预览台（§7.4）。

## 1. 状态机

### 1.1 画布没有选中面（用户裁定：画布不是编辑器）

画布只重排、只高亮，不选中、不编辑：点卡片没有任何选中效果，点空白不弹检查器。选中与编辑全部住在列表模式（列表行 → 编辑器席位 → 链接两段）。

理由：画布是「看见关系」的面，编辑是「改一张卡」的面。把两者塞进同一块坐标，任何一次拖动都要先回答「这是重排还是选中」，手势会互相吞。

### 1.2 视口状态机

```
[初始] --布局+尺寸就绪--> [打开视口]（每 viewKey=owner 一次：0.85 缩放对准枢纽质心）
[打开/任意] --滚轮(光标锚)--> [缩放 0.25–2.0]
[任意] --指针按下画布背景→移动≥4px--> [平移] --松开--> [原状态]
[任意] --工具条 +/− --> [中心锚缩放 ×1.25 / ×0.8]
[任意] --工具条"适配" --> [适配整幅图]
```

- 打开视口不是「适配」：旧的打开即适配把九张卡压到约 0.5，13px 标题在屏上只有 6px。适配仍是工具条的显式动作。
- 平移由 Konva 舞台自带的拖拽承担（`stage.draggable(true)` + `dragDistance(4)`），指针位置回写 React 视口态；卡片组自带拖拽，Konva 让内层可拖拽优先，因此抓卡片绝不连带平移画布。
- 按下即由手势仲裁者（`canvas-gesture.ts`）取消浏览器默认手势：平移不刷文字选中、不起原生拖拽；触摸保留浏览器自己的手势。

### 1.3 边悬停状态机

```
[无悬停] --指针入边的 12px 命中描边--> [悬停边 i]
[悬停边 i] --两端点亮、邻域保持，其余节点 .3 / 其余边 .18 -->  --指针离线--> [无悬停]
```

- 命中面是画布路径的 `hitStrokeWidth: 12`，墨线本身 1.6px；同一条贝塞尔同时承担命中与绘制，命中面不会与墨迹漂移。

## 2. 解剖图

### 2.1 卡节点（176×84px，分区几何由 canvas-layout 决定）

```
┌──────────────────────────┐
│ [闪念|永久|项目]      ⟲3 │  kind 章 + 入链角标（>0 才显示）
│ 标题（13px，一行截断）     │
│ 摘要（10.5px，两行截断）   │  excerpt 空则不占位
│ 剩 2 天 / 已过期 1 天      │  仅带 expiresAt 的卡；overdue 红字
└──────────────────────────┘
```

- 卡片是一个 Konva Group：圆角底、可选项目条、类别章（按实测文案宽度的胶囊）、入链角标、标题、摘要、老化行全部是场景图节点。
- 悬停/压暗：邻域外节点 `opacity .3`、无关边 `.18`。
- 项目卡左侧 3px 成功色条；闪念卡底色为 accent-soft 30% 混合 surface；overdue 卡虚线描边 + 红字。

### 2.2 边

- 墨线 1.6px（accent 混 border），二次贝塞尔沿弦法线弯曲（`edgePath`，与布局同源、确定且与顺序无关），避免两条弦在中心交叉成 X。
- 命中描边 12px，悬停点亮邻域。

### 2.3 分区（canvas-layout 的领域几何）

```
            ┌─ 枢纽环（入链>0，最内）
   图区三环 ├─ 流出环（仅出链）
            └─ 孤岛环（全无链接，最外——审计显影带）
────────────────────────────────
   进料带（4 列网格）：过期在前（自左上），新鲜在后   ← 闪念永不入图，天然分区
```

## 3. 密度阶梯（D6）

| 卡数 | 形态 |
|---|---|
| ≤30 | 全细节（标题+两行摘录+角标）——默认 0.85 打开档；当前真实盒 9 卡在此档 |
| 31–150 | 本期不变（布局已按弧长防重叠自动外扩）；LOD 缩放驱动裁剪留 P1 |
| >150 | 本期可画（200 卡合成通过、bounds 5258×6758）；粗粒度态留 P1 |

0.85 档即「全细节」：卡标题 13px，屏上 11.05px，无需任何操作可读；适配（fit）是显式动作，不承担默认可读性。

## 4. 主题 token（Konva 无 CSS 继承，改为活文档读取）

| 画布元素 | 来源 |
|---|---|
| 卡底/画布底 | `--nb-surface` → `--dsw-alias-bg-layer-1` |
| 边墨 | `--nb-accent` 62% 混 `--nb-border`（`mixColor`） |
| 类别章底 | `--nb-sunken` |
| overdue 文/框 | `--nb-danger` |
| 项目条 | `--nb-success` |
| 卡阴影 | `--nb-text` 8% alpha（`withAlpha`） |
| 闪念底 | `color-mix(in srgb, var(--nb-accent-soft) 30%, var(--nb-surface))` 由探针解析 |

`canvas-theme.ts` 在页面内放一个隐藏探针，把 `var(--nb-*)` 写进会被绘制的属性再读 `getComputedStyle`，因此整条别名链（含 `color-mix`）由浏览器解析；`body[data-ds-dark-theme]` 与根属性的 `MutationObserver` 在外壳换主题时重建调色板。多主题零硬编码色。

## 6. 过期语义（D3 落地面）

- 窗口：`freshness.fleetingWindowDays`（默认 2，钳 [1,365]），只改可见性，绝不删行。
- `expiresAt = updatedAt + 窗` 读时派生；卡片/列表行/进料口三处同源渲染。
- 出口：**炼成**（dock/编辑器一键，走完整写入纪律）｜**扔**（dock 两击确认，走 card-referenced 守卫）｜**编辑**（保存即刷新 updatedAt，自然续鲜）。
- 无 snooze、无定时器、无自动删除（教义：docs/notebook-note-types.cn.md §2）。

## 7. 渲染引擎（rc.3）

### 7.1 结论

渲染层是 **Konva 10（Canvas2D 场景图，MIT）**，按需从子路径导入（`konva/lib/Stage`、`Layer`、`Group`、`shapes/Rect`、`shapes/Text`、`shapes/Path`），随客户端 bundle 内联。没有任何卡片是 DOM 元素。

### 7.2 为什么换

- **DOM 卡片的天花板是布局引擎**：每张卡是一个带文本折行、边框、阴影、`transition` 的 DOM 盒子，全在一个 `transform: scale()` 的世界里；每帧的拖拽要重排整棵子树，节点数一多先崩的不是画布而是样式解析与合成。
- **命中测试**：DOM 用 `closest('[data-canvas-node]')` 把「点到了谁」交给选择器；canvas 用库的命中画布（每个 shape 一个 colorKey），层级、透明度、描边宽度全部参与命中，边与卡的优先级由场景图顺序决定。
- **文本**：库自带折行/省略号/行高，卡片解剖的每一行都有一条明确的文本带（标题 13px 一行、摘要 10.5px 两行、老化行 10px），不依赖 `-webkit-line-clamp` 这类仅 DOM 的裁剪。
- **手势**：拖拽（带 3px 阈值）、舞台平移（4px 阈值）、层级提升（`moveToTop`）是库的一等公民，不必自己维护指针捕获与 z-index。
- **主题**：canvas 没有 CSS 继承，因此颜色必须显式解析（§4）；换主题时重建调色板而不是等浏览器重绘 CSS 变量。

### 7.3 结构与职责

| 文件 | 职责 |
|---|---|
| `canvas-layout.ts` | 纯几何：分区、环、进料带、边界、贝塞尔路径（无 React、无 Konva） |
| `canvas-card.ts` | 一张卡的场景图：卡身、项目条、类别章、角标、标题、摘要、老化行 |
| `canvas-scene.ts` | 一层图层里的边层 + 卡层，悬停压暗与拖拽中的边重接 |
| `canvas-theme.ts` | 活主题 → 调色板（隐藏探针 + MutationObserver） |
| `canvas-color.ts` | `rgb()`/hex 解析、`color-mix` 与 alpha 的算术替身（纯函数） |
| `canvas-position-store.ts` | 拖拽位置：localStorage 读写，损坏条目静默丢弃（纯函数） |
| `canvas-viewport-math.ts` | 缩放边界、适配视口、打开视口（纯函数） |
| `canvas-viewport-auto.ts` | 上述算术的 React 绑定：量尺寸、滚轮缩放、打开视口、缩放动作 |
| `use-canvas-stage.ts` | Konva 舞台生命周期：建/毁、尺寸、变换、场景重建、拖拽手势、手势仲裁 |
| `canvas-stage.tsx` | 舞台元素本身（一个 div） |
| `canvas.tsx` | 组装：工具条、舞台、空盒指引卡 |

### 7.4 验收

- 纯函数：`tests/canvas-{layout,color,positions}.spec.ts`（布局不变式、混色/解析、位置往返与损坏丢弃）。
- 交互：真实 Chrome 预览台（同一组件、同一份 `panel.css` + `canvas.css`、真实主题 CSS）自动验证——画布元素恰为 1；拖卡片后 `localStorage` 出现取整后的落点；悬停边整幅重绘（邻域压暗）；背景拖拽平移重绘；滚轮缩放重绘；`body[data-ds-dark-theme]` 切换后画布重绘；全程无 page error / console error。
- 无障碍：舞台 `aria-hidden`，列表模式是等价面（§1.1）。

### 7.5 代价

- 客户端 bundle 由约 105KB 增至约 449KB（Konva 子集内联、未压缩）。收益是节点数不再受 DOM 布局约束，且拖拽/命中/文本折行由库保证。
- 文本度量跟随字体：卡片的行高与省略号由 Konva 在运行时量，主题的 `--dsw-font-family` 变化同样触发调色板重建（字体族在调色板里）。
