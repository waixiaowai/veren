## 1. 三个状态机

### 1.1 选中状态机（画布 ↔ 浮动检查器同源）

```
[无选中] --点节点/点边(取目标)/列表行/进料口标题--> [选中 id]（浮动检查器打开）
[选中 id] --再点另一节点/另一边--> [选中 新 id]     （本地切换，零网络）
[选中 id] --点空画布 / 检查器 ×--> [无选中]（显式清除后保持清除，不自动回选）
[选中 id] --炼成成功--> [选中 新永久卡 id]          （promote 返回值驱动）
[选中 id] --删除/扔成功--> [无选中]
```

- 自动选中闸：每盒只在从未选中过时自动选第一条；显式清除（空画布/×）后不再自动回选，换归属重置。

- 选中即编辑器草稿载入（`applyNoteSelection`）；dirty 草稿不被轮询覆盖（既有守卫）。
- 选中是纯本地状态：画布上任何选中切换**不产生网络请求**（验收项 5）。

### 1.2 视口状态机

```
[初始] --布局+尺寸就绪--> [适配 fit]（每 fitKey=owner 一次）
[适配] --滚轮(光标锚)--> [缩放 0.25–2.0]
[适配/缩放] --指针按下→移动≥4px--> [平移] --松开--> [原状态]
[任意] --工具条 +/− --> [中心锚缩放 ×1.25 / ×0.8]
[任意] --工具条"适配" --> [适配]
```

- 点击与拖拽的分界：4px 内是纯点击（落到节点/边命中线的真目标），越阈才捕获指针进入平移——因此边线与节点按钮的原生 click 不被指针捕获吞掉。

### 1.3 边悬停状态机

```
[无悬停] --指针入命中线(12px 透明)--> [悬停边 i]
[悬停边 i] --两端点亮/邻域保持、其余节点与边压暗 -->  --指针离线--> [无悬停]
[悬停边 i] --点击--> [选中 targetId]（顺边走）
```

## 2. 解剖图

### 2.1 卡节点（176×84px，分区几何由 canvas-layout 决定）

```
┌──────────────────────────┐
│ [闪念|永久|项目]      ⟲3 │  kind 章 + 入链角标（>0 才显示）
│ 标题（一行截断）           │
│ 摘要（两行截断）           │  excerpt 空则不占位
│ 剩 2 天 / 已过期 1 天      │  仅闪念卡；overdue 红字
└──────────────────────────┘
```

- 选中：accent 描边 + 外圈；悬停：accent 边；压暗（邻域外）：opacity .3。
- 项目卡左侧 3px 成功色条；闪念卡底色微 accent；overdue：虚线边 + 褪色。

### 2.2 边

- 墨线 1.5px（accent 混边框色）；悬停命中线 12px 透明（可点面）。
- 悬停时：命中边保持、无关节点 opacity .18 / 节点 .3。

### 2.3 分区（canvas-layout 的领域几何）

```
            ┌─ 枢纽环（入链>0，最内）
   图区三环 ├─ 流出环（仅出链）
            └─ 孤岛环（全无链接，最外——审计显影带）
────────────────────────────────
   进料带（4 列网格）：过期在前（自左上），新鲜在后   ← 闪念永不入图，天然分区
```

## 6. 过期语义（D3 落地面）

- 窗口：`freshness.fleetingWindowDays`（默认 2，钳 [1,365]），只改可见性，绝不删行。
- `expiresAt = updatedAt + 窗` 读时派生；节点/列表行/进料口三处同源渲染。
- 出口：**炼成**（dock/编辑器一键，走完整写入纪律）｜**扔**（dock 两击确认，走 card-referenced 守卫）｜**编辑**（保存即刷新 updatedAt，自然续鲜）。
- 无 snooze、无定时器、无自动删除（教义：docs/notebook-note-types.cn.md §2）。
