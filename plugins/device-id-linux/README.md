# @veren/device-id-$tag

The $($s.os) platform plugin for `@veren/device-id`. Provides the
`device-id-platform` capability: the stable-tier hardware fingerprint
($($s.fp)) and the out-of-band anchor ($($s.an)).

Install this INSTEAD of the other platform variants on $($s.os) hosts,
alongside the `@veren/device-id` core package.
