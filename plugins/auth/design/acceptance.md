## 11. System Acceptance

本章描述整套系统最终验收条件，不分期。每项含编号、场景、前置条件、操作、预期结果与验证方式；覆盖端到端业务、跨模块契约、权限、异常恢复、页面状态恢复与非功能目标。模块级验收见各模块章 [2.5](./modules/02-endpoint/#25-acceptance)、[3.5](./modules/03-session/#35-acceptance)、[4.5](./modules/04-credential/#45-acceptance)、[5.5](./modules/05-identity/#55-acceptance)、[7.5](./modules/07-guard/#75-acceptance)、[8.5](./modules/08-storage/#85-acceptance)。

### 11.1 End-to-end Acceptance

| 编号 | 场景 | 前置条件 | 操作 | 预期结果 | 验证方式 |
|---|---|---|---|---|---|
| E1 | 口令注册到登录闭环 | 已装配存储与邮箱口令 | 注册 → 登录 → 读会话 → 登出 | 注册建档并自动登录；会话可读回；登出后凭据失效且记录删除 | 集成测试 + 真机 |
| E2 | 第三方登录闭环 | 配置一个提供方 | 授权 → 回调 → 读会话 | 主体与绑定同事务建立；会话签发；二次登录走绑定直通 | 集成测试（提供方 mock）+ 真机 |
| E3 | 邮箱校验闭环 | 强校验开启 | 注册 → 收信核销 → 登录 | 未验证登录被拒 `EMAIL_NOT_VERIFIED`；核销后登录成功 | 集成测试 |
| E4 | 口令重置闭环 | 存在凭证账号 | 申请重置 → 核销令牌设新口令 → 旧口令登录 | 新口令可登录；旧口令失败；令牌不可复用 | 集成测试 |
| E5 | 邀请闭环 | 组织域装配 | 建组织 → 邀请 → 接受 → 成员可见 | 邀请状态两段式转移；成员行建立；重复接受被拒 | 集成测试 + 真机 |
| E6 | 二次验证闭环 | 强认证域装配 | 启用 TOTP → 登录触发挑战 → 验证码通过 | 挑战前不出会话；验证通过签发会话；备份码可用一次 | 集成测试 + 真机 |
| E7 | 设备授权闭环 | 设备授权扩展装配 | 设备申请码 → 已登录方批准 → 设备轮询兑换 | 兑换出会话且记录删除；二次兑换 `DEVICE_CODE_ALREADY_PROCESSED` | 集成测试 |
| E8 | 跨标签会话同步 | 同一浏览器多标签 | A 标签登出 | B 标签会话原子在广播后刷新为未登录态 | 浏览器测试 |

### 11.2 Cross-module Contract

| 编号 | 场景 | 预期结果 | 验证方式 |
|---|---|---|---|
| C1 | 钩子管线双入口一致性 | 同一 before 拦截钩子对 HTTP 与 `auth.api.*` 均生效 | 单测 |
| C2 | server-only 端点隔离 | HTTP 访问 404；服务端调用正常；不出现在 OpenAPI 导出 | 单测 |
| C3 | 插件表贡献合并 | 后声明插件覆盖先声明插件的同名字段；模型改名生效 | 单测 |
| C4 | 错误码统一 | 同一失败在不同端点返回同一码（如来源非法处处 `INVALID_ORIGIN`） | 单测 |
| C5 | 会话缓存旁路 | 敏感端点（吊销类）即使缓存副本有效也读权威源 | 集成测试 |
| C6 | 等时失败 | 未注册邮箱与错误口令的响应时长同量级、错误码一致 | 单测（时序断言） |

### 11.3 Permission and Isolation

| 编号 | 场景 | 操作 | 预期结果 | 验证方式 |
|---|---|---|---|---|
| P1 | 越权拒绝 | 未认证访问 `/revoke-session` | 401 `UNAUTHORIZED` | 集成测试 |
| P2 | 跨主体不可见 | 主体甲吊销主体乙的会话 | 返回未找到/禁止；乙的会话不受影响 | 集成测试 |
| P3 | 组织隔离 | 成员访问非所属组织端点 | `USER_IS_NOT_A_MEMBER_OF_THE_ORGANIZATION` | 集成测试 |
| P4 | 主体切换失效 | 切换活跃组织后再查成员列表 | 返回新组织作用域；旧组织上下文不残留 | 真机 |
| P5 | 角色门禁 | 非 admin 角色调管理端点 | `YOU_ARE_NOT_ALLOWED_*` 系列码 | 集成测试 |
| P6 | 非法状态转移 | 终态邀请再接受 | 原子认领失败拒绝，对应 `states.md` 失败码 | 单测 |

### 11.4 Failure and Recovery

| 编号 | 场景 | 操作 | 预期结果 | 验证方式 |
|---|---|---|---|---|
| R1 | 存储抖动恢复 | 建会话时存储瞬时失败 | 返回 `FAILED_TO_CREATE_SESSION`；重试成功后无残留半状态 | 故障注入 |
| R2 | 注册事务回滚 | 建档成功但建凭证失败 | 事务整体回滚，无幽灵用户 | 单测 |
| R3 | 过期凭据恢复 | 携带过期会话凭据请求 | 记录删除、凭据清除、返回空；重新登录恢复 | 集成测试 |
| R4 | 限流恢复 | 触发 429 后等待 `X-Retry-After` | 窗口重置后请求放行 | 集成测试 |
| R5 | 邀请建行失败释放 | 接受邀请时建成员行失败 | 状态释放回 `pending`，可重试 | 单测 |
| R6 | 密钥轮换 | 配置多版本密钥后用旧密钥期凭据 | 旧凭据仍可校验；新签发用新版本 | 单测 |

### 11.5 Page State and Non-functional

| 编号 | 场景 | 预期结果 | 验证方式 |
|---|---|---|---|
| S1 | 页面四态 | 消费方页面逐页具备加载/空/失败/无权限态与降级（见 [10.4](./components/pages/#104-page-components)） | 走查 + 浏览器测试 |
| S2 | 键盘可达 | 错误页与表单页键盘完整可用，焦点可见 | 浏览器测试 |
| S3 | 深浅主题 | 错误页跟随系统深浅色，对比度达标 | 浏览器测试 |
| S4 | 深链恢复 | 携带 `token`/`callbackURL` 的页面刷新后状态不丢，敏感令牌用后即换 | 浏览器测试 |
| S5 | 限流响应 | 429 携带 `X-Retry-After`；文案可重试提示 | 集成测试 |
| S6 | 接口参考 | `/reference` 页可浏览全部非 server-only 端点 | 真机 |
