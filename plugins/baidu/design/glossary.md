## 15. Domain Glossary

| 中文名 | 统一标识 | 解释 | 易混淆边界 |
|---|---|---|---|
| 百度网盘 | `drive` | 提供文件存储与检索的外部服务，是本系统能力的最终执行方 | 不是本系统自身；本系统只是调用方 |
| 应用沙盒 | `app_sandbox` | 账号下授予本应用的目录 `/apps/bdpan`，是所有文件操作的资源边界 | 不是账号根目录；账号其他目录不可访问 |
| 沙盒根 | `sandbox_root` | 沙盒的顶层路径 `/apps/bdpan` | 与"根目录 `/`"不同，后者指账号根 |
| 展示路径 | `display_path` | 面向用户的路径形式"我的应用数据/bdpan/…" | 不是调用参数；调用仍用 `/apps/…` |
| 授权码 | `auth_code` | 用户在浏览器完成授权后得到的 32 位十六进制字符串，用于换取令牌 | 不是令牌；一次性使用 |
| 访问令牌 | `access_token` | 调用服务时携带的短时凭据 | 不是刷新令牌；不用于续期 |
| 刷新令牌 | `refresh_token` | 用于换取新访问令牌的长时凭据 | 刷新失败即失效，必须重新授权 |
| 会话 | `session` | 一次 Agent 对话或一次协议连接，携带归因上下文 | 不是账号；不拥有数据 |
| 宿主 | `host` | 承载会话的运行时（Agent 宿主或协议宿主） | 不是本系统组件 |
| 转存 | `transfer` | 把他人分享的文件保存到自己网盘，不下载到本地 | 与"下载"不同：下载落本地，转存落网盘 |
| 选择性转存 | `transfer_select` | 只转存分享中的部分条目 | 不是"分批转存"；客户端不自动拆分 |
| 提取码 | `share_pwd` | 访问分享内容所需的 4 位口令 | 不是授权码，不涉及账号身份 |
| 分享链接 | `share_link` | 指向分享内容的地址，可带提取码参数 | 不是回端链接 |
| 回端链接 | `return_link` | 由链接服务生成的、可点击回到网盘定位文件的地址 | 不是分享链接，也不是 Web 首页 |
| 拉端页 | `spirit_launch` | 回端链接的统一落地页，文件与目录目标由参数区分 | 不是预览页；能否预览由网盘主端判断 |
| 正文片段 | `snippet` | 检索返回的文档命中片段 | 可能是"索引生成中"的占位文案，不是原文 |
| 正文解析 | `parse` | 把文档转换为可读正文的过程，可能异步 | 不是"下载"；解析在服务端完成 |
| 任务号 | `task_id` | 异步任务（转存、解析）的标识，用于轮询 | 不是文件标识 |
| 文件标识 | `fsid` | 文件的唯一标识，必须按字符串传输 | 不是路径；同一文件可有不同路径 |
| 超级会员 | `svip` | 支持正文检索等增强能力的会员类型 | 不是普通会员；预检必须区分 |
| 容量到期 | `quota_expire` | 7 天内有容量到期，不代表全部到期 | 不是"立即到期" |
| 记忆备份 | `memory_backup` | 把宿主工作区的长期记忆文件打包上传到沙盒固定目录 | 不是普通文件上传；必须经清单 |
| 记忆清单 | `manifest` | 描述一次备份的元数据与文件列表 | 不是目录索引；只描述单次备份 |
| 安全网 | `safety_net` | 恢复前在本地留存的当前记忆副本 | 不是远端备份；仅本地 |
| 设备名 | `device_name` | 归一化后的主机名，用于区分不同设备 | 不是账号；同账号多设备共享备份列表 |
| 来源归因 | `attribution` | 宿主名、会话标识、原始提问、归因标识，用于服务质量追踪 | 不是身份凭据；缺失不阻断执行 |

## 16. Technical Glossary

| 术语 | 解释 | 在本方案中的用途 |
|---|---|---|
| OAuth 2.0 | 授权框架，允许第三方在用户授权下访问资源 | 描述授权码与刷新令牌流程，不展开协议细节 |
| 回显码模式（OOB） | 无回调地址时，由用户手工复制授权码完成授权 | 终端与无浏览器环境的主要授权方式 |
| 设备码 | 面向无浏览器设备的授权方式，服务端返回用户码供人工确认 | 开发库的设备授权方法 |
| 标准输入输出传输 | 宿主以子进程方式拉起网关，通过 stdin/stdout 交换协议消息 | 协议网关的本地形态 |
| 服务端事件流 | 一种长连接推送方式，常用于远端工具目录 | 协议网关的远端形态 |
| 工具目录 | 宿主可发现的能力清单，含名称、说明与参数模式 | 协议层的对外契约 |
| 参数模式（JSON Schema） | 描述工具参数的类型、必填与取值范围 | 工具接口的校验依据 |
| 分片上传 | 把大文件切成固定大小块分别上传再合并 | 单文件上传的三步流程之一 |
| 秒传 | 服务端已存在相同内容时直接建立文件记录 | 上传流程的分支，需要正确处理 |
| 预创建 | 上传前向服务端登记路径、大小与分片摘要 | 获取上传标识与缺失分片列表 |
| 直链 | 带签名与时效的下载地址 | 流式下载的来源，需当作不透明值 |
| 签名地址 | 带时效与权限参数的临时地址 | 超长正文的临时下载方式（2 小时） |
| 指数退避 | 重试间隔按倍数增长 | 网络与限流错误的重试策略 |
| 幂等 | 同一操作重复执行的结果与执行一次相同 | 判定重试是否安全（写入与提交类操作不幂等） |
| 状态机 | 用状态与转移描述实体生命周期 | 授权、上传、转存、解析四类实体的建模 |
| 契约 | 接口的输入输出与失败约定 | 模块章与接口章的统一定义来源 |
| 输出信封 | 统一的返回结构（码、数据、错误、元信息） | 收敛三种输出形态的目标设计 |
| 路径归一化 | 折叠重复分隔符、解析相对段并校验边界 | 防穿越的核心步骤 |
| 编码穿越 | 用百分号编码隐藏父目录段 | 路径校验必须拒绝的形式 |
| 传输名 | 接口上的字段名（小写下划线） | 数据字典与 JSON 示例的写法 |
| 契约名 | 代码中的字段名（驼峰） | 模块契约的写法，与传输名一一对应 |
| 无障碍（a11y） | 让不同能力用户都能使用产品 | 对比度、焦点、键盘、屏幕阅读器规则 |
| 国际化（i18n） | 让产品适配不同语言与地区 | 中英双语、日期数字格式、文案长度余量 |
| 减少动效偏好 | 操作系统提供的"减少动画"设置 | 动效降级规则的触发条件 |
| 深链接 | 直接定位到页面某一章节的链接 | 方案站点锚点与折叠展开的行为 |
| 预渲染 | 在构建期生成静态产物而非运行时渲染 | 图与方案站点的构建期渲染策略 |
