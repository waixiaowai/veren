## 4. Permissions and Subjects

本章先定义"主体"——承担数据归属与权限判定的单位——再给出唯一的权限矩阵，接口、页面与组件三处的权限描述都引用该矩阵，不另立口径。

### 4.1 Subjects

| 主体 | 定义 | 数据归属 | 是否可切换 | 判定依据 |
|---|---|---|---|---|
| 账号主体 | 一次授权所对应的百度账号，是文件与容量的最终归属者 | 账号下的全部文件、容量、任务、分享 | 是（通过切换凭据文件或重新授权） | 本机凭据库中的账号引用 |
| 沙盒主体 | 账号下授予本应用的目录 `/apps/bdpan`，是文件操作的资源边界 | 沙盒内的文件与目录 | 否（随账号固定） | 归一化后的路径前缀 |
| 会话主体 | 一次 Agent 会话或一次协议连接，是动作的发起者 | 不拥有数据，只携带归因上下文（宿主名、会话标识、原始提问、归因标识） | 是（新会话即新主体） | 调用时注入的上下文 |
| 集成主体 | 一个开发者应用或一个协议宿主的接入身份 | 不拥有数据，代表账号行使被授予的能力 | 是（不同应用各自授权） | 授权时签发的令牌与范围 |

默认主体规则：未显式指定时，沙盒主体固定为当前账号下的 `/apps/bdpan`；会话主体取当前对话；集成主体取当前连接。系统不支持"跨账号代操作"：任何请求只能以一个账号主体的身份发出。

### 4.2 Permission Matrix

判定只取"允许""拒绝""条件"三值；条件必须写明依据字段。矩阵行覆盖命令、工具、库三类接口涉及的全部操作。

| 角色 | 资源 | 操作 | 判定 | 条件 |
|---|---|---|---|---|
| 用户 | 本机凭据 | 读取 | 拒绝 | 凭据内容永不面向用户展示；仅显示账号名与到期时间 |
| 用户 | 本机凭据 | 清除 | 允许 | 需显式执行注销 |
| Agent | 本机凭据 | 读取 | 拒绝 | 禁止读取、输出、复制凭据文件 |
| Agent | 授权流程 | 发起 | 条件 | 只在用户明确要求或有前置任务时；必须展示安全须知并取得确认 |
| Agent | 沙盒内文件 | 读取（列表、检索、读正文） | 允许 | 路径归一后在 `/apps/bdpan` 内 |
| Agent | 沙盒内文件 | 写入（上传、建目录、移动、复制、重命名） | 条件 | 路径明确；中危操作在路径含糊时先确认 |
| Agent | 沙盒内文件 | 覆盖写入 | 条件 | 用户明确要求覆盖 + 会话中二次确认 + 目标已存在 |
| Agent | 沙盒内文件 | 删除 | 条件 | 用户明确提出删除 + 逐项列出对象 + 明确确认；不得主动建议删除 |
| Agent | 分享链接 | 创建 | 允许 | 目标在沙盒内；有效期取 0/1/7/30 |
| Agent | 分享转存 | 提交 | 条件 | 目标目录在沙盒内；选择性转存需展示清单并确认 |
| Agent | 记忆备份目录 | 写入 | 条件 | 仅经受控脚本；仅四类宿主环境 |
| Agent | 记忆备份目录 | 恢复写回 | 条件 | 清单校验通过 + 本地安全网成功 + 跨宿主需强制 |
| Agent | 环境变量 | 设置 | 拒绝 | 禁止代为设置配置路径、安装目录、二进制路径等变量 |
| Agent | 技能包与命令 | 更新 | 条件 | 仅用户明确指令；禁止自动或静默更新 |
| 协议宿主 | 账号下文件 | 读取 | 条件 | 令牌有效；路径为绝对路径；仅限该账号 |
| 协议宿主 | 账号下文件 | 写入 | 条件 | 同上；危险工具需会话确认凭证 |
| 协议宿主 | 本地文件 | 读取 | 拒绝 | 远端形态不提供本地上传；本地形态仅 `MCP-UPLOAD-LOCAL` |
| 开发者应用 | 账号下文件 | 读写 | 条件 | 令牌有效且路径在授权根内；由应用自行承担确认责任 |
| 开发者应用 | 本机凭据库 | 访问 | 拒绝 | 库层不读写本机凭据库，凭据由应用注入 |
| 任何角色 | 沙盒外路径 | 任意 | 拒绝 | 统一返回 BDPAN_PATH_OUT_OF_SCOPE，不发起上游请求 |
| 任何角色 | 他人账号数据 | 任意 | 拒绝 | 不存在跨账号接口；越权一律按未授权处理 |

矩阵的三条硬约束：其一，"拒绝"不可通过参数覆盖，也不存在管理员开关；其二，"条件"未满足时必须返回明确错误码，不得降级为"允许但静默失败"；其三，同一能力在接口与页面上的判定必须一致——页面显示"不可用"的操作，接口也必须拒绝。

### 4.3 Isolation

查询范围：所有列表、检索、正文、容量之外的读操作，默认且只能作用于当前账号的沙盒前缀；检索类接口额外接受目录参数，但该参数同样必须落在沙盒内。

越权返回：统一为 BDPAN_PATH_OUT_OF_SCOPE（本地拒绝）或 BDPAN_FORBIDDEN（上游拒绝），不区分"路径不存在"与"无权访问"，避免通过错误差异探测他人目录结构。

跨主体可见性：不存在跨账号聚合。列表与统计只统计当前账号沙盒内对象；容量是账号级只读元数据，不扩大文件访问范围，也不出现在列表结果中。

### 4.4 Subject Switch

切换账号（重新授权或切换凭据文件）后，下列状态必须立即失效，不得复用：

| 状态 | 失效方式 | 失效时机 | 若未失效的后果 |
|---|---|---|---|
| 内存中的用户标识缓存 | 清空 | 凭据变更后首个请求前 | 检索会被带到旧账号目录下 |
| 分页游标与偏移 | 重置到第一页 | 主体切换或筛选变化 | 翻页出现错位或重复条目 |
| 任务标识（转存、解析） | 视为不可用，不跨主体查询 | 主体切换 | 用旧任务号查到他人任务或误报失败 |
| 确认凭证 | 全部作废 | 主体切换、对象集合变化 | 用旧确认执行新对象，等同于绕过确认 |
| 回端链接 | 不缓存、不跨主体复用 | 每次结果重新生成 | 链接指向旧账号资源 |
| 凭据文件句柄 | 关闭并重新打开 | 主体切换 | 继续以旧身份写入 |

切换主体的界面提示固定为一句完整的话：说明"已切换账号，当前仅能看到新账号的『我的应用数据/bdpan』"，并清除上一账号的结果列表；不得把两个账号的结果混排在同一回复中。
