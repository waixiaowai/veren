## 9. UI and Interaction

本系统的界面由三部分构成：终端里的字符界面、会话里的文本回复、方案站点里的文档界面。三者共用同一套语义令牌（颜色、间距、状态、动效），但落地方式不同：终端受 ANSI 色板与等宽网格约束，会话受宿主渲染能力约束，方案站点受浏览器约束。本章逐项给出取值与规则；确实不适用的条目在 9.1 与对应小节写明依据，不虚构。

### 9.1 Scope

| 条目 | 是否适用 | 依据 |
|---|---|---|
| 色彩、间距、字体、布局 | 适用 | 终端与方案站点都需要明确的视觉层级 |
| 微交互 | 适用（受限） | 终端只有闪烁、进度刷新与确认提示；不适用的动画形式（位移动画、悬停反馈）不定义 |
| 微文案 | 适用 | 用户可见文本全部是文案 |
| 无障碍 | 适用 | 终端需支持屏幕阅读器与无色模式；方案站点需键盘可达 |
| 国际化 | 适用 | 面向中文与英文用户 |
| 图标与插图 | 部分适用 | 方案站点与原型用 SVG；终端不渲染图标，只使用文字状态标签 |
| 图片、视频、音频 | 不适用 | 产品不承载内容媒体：文件预览由网盘主端负责，本系统只给链接 |
| 自定义滚动条 | 不适用 | 终端无滚动条；方案站点使用浏览器原生滚动条，不自定义 |
| 主题 | 适用 | 方案站点明暗主题；预渲染图统一白底，不随主题反转（保证图内固定深色文字的对比度）；终端跟随 `NO_COLOR` 与终端色板 |

### 9.2 Color

色彩只用于强化语义，不承担唯一信息载体：每个状态同时有文字标签（`成功`/`失败`/`等待`/`需确认`），色觉差异用户不依赖颜色也能读懂。

| 语义令牌 | 浅色值 | 深色值 | 用途 | 对比度（对背景） |
|---|---|---|---|---|
| `--bg` | `#FFFFFF` | `#0D1117` | 页面背景 | — |
| `--surface` | `#F6F8FA` | `#161B22` | 卡片、代码块底 | 正文对比 ≥12:1 |
| `--text` | `#1F2328` | `#E6EDF3` | 正文 | 15.3:1 / 14.1:1 |
| `--muted` | `#57606A` | `#9DA7B3` | 辅助说明、时间戳 | 6.3:1 / 7.0:1 |
| `--border` | `#D0D7DE` | `#30363D` | 分隔线、表格边框 | 3.1:1（非文本） |
| `--brand` | `#1A56DB` | `#6CA0FF` | 链接、主按钮、焦点 | 5.8:1 / 6.9:1 |
| `--success` | `#137333` | `#6FCF97` | 成功状态 | 5.4:1 / 8.9:1 |
| `--warning` | `#A15C00` | `#F2C94C` | 等待、需确认 | 5.1:1 / 12.3:1 |
| `--danger` | `#B42318` | `#FF8A80` | 失败、删除 | 6.4:1 / 7.7:1 |
| `--disabled` | `#6E7781` | `#6E7781` | 禁用文本 | 4.6:1（仅用于非关键信息） |

终端映射：`--brand` 对应 ANSI 蓝（`\e[34m`），`--success` 绿（`\e[32m`），`--warning` 黄（`\e[33m`），`--danger` 红（`\e[31m`），`--muted` 亮黑（`\e[90m`），`--border` 默认前景色。终端禁止使用 256 色与真彩色作为唯一编码；`NO_COLOR` 或 `TERM=dumb` 时全部退化为纯文本，状态改由方括号标签表达。

### 9.3 Spacing and Type

间距以 4 px 为基数：`4` 用于同一控件内部（图标与文字）、`8` 用于相关字段（标签与值）、`12` 用于组件组（表格行内分区）、`16` 用于区块（表格与说明之间）、`24` 用于章节、`32` 用于页面上下留白。终端没有像素，等价尺度为字符格：同一行内字段间隔 2 空格，列表缩进 2 空格，区块之间空 1 行，章节之间空 2 行。

| 层级 | 字体族 | 字号/字重 | 行高 | 颜色 | 备注 |
|---|---|---|---|---|---|
| 方案站点主标题 | 系统无衬线 + 中文回退 | 28/700 | 1.25 | `--text` | 每页一个 |
| 方案站点章节标题 | 同上 | 20/650 | 1.3 | `--text` | 与导航同步 |
| 区块标题 | 同上 | 16/600 | 1.4 | `--text` | 小节标题 |
| 正文 | 同上 | 15/400 | 1.65 | `--text` | 段宽 ≤ 78 字符 |
| 辅助文字 | 同上 | 13/400 | 1.5 | `--muted` | 时间、来源、提示 |
| 表格与数据 | 等宽栈 | 13/400 | 1.5 | `--text` | 数字右对齐 |
| 终端正文 | 等宽栈 | 终端默认 | — | 终端前景 | 行宽 ≤ 100 列 |
| 终端标签 | 等宽栈 | 同行 | — | 语义色 | `[成功]`、`[失败]` |

等宽栈（按序回退）：`Cascadia Mono`、`JetBrains Mono`、`SFMono-Regular`、`Consolas`、`Liberation Mono`、`monospace`；无衬线栈：`Segoe UI`、`PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC`、`sans-serif`。长文本规则：段落自动换行不加连字符；文件名超过 40 字符时中间省略（保留前 12 与后 8），完整值只在 `--json` 与悬停提示中出现；路径超过 60 字符时同样中间省略，禁止只显示末尾导致根目录不可见。

### 9.4 Layout

方案站点：导航、正文与右侧目录由站点主题提供，本方案不覆盖其栅格与断点，只要求表格可横向滚动、图不溢出容器、窄屏导航可收起；终端布局仍按 80 列设计。

终端：默认按 80 列设计，超过 100 列不额外拉伸；表格列顺序固定为"名称 / 大小 / 时间 / 链接"，名称列最小 12 字符、可伸缩，大小列右对齐 10 字符，时间列 19 字符（`YYYY-MM-DD HH:mm:ss`），链接列固定在最右且整体保留；多行结果每行一条，项目之间不留空行；摘要行（`共 N 项`）固定放在表格之后，与表格间隔 1 行。

表单与确认：终端确认提示独占一行，格式为"动作 + 对象 + 后果 + `[y/N]`"，默认 `N`；不得用回车默认确认危险操作。会话确认：对象清单用列表呈现，逐项含路径与类型，末尾给出一句后果说明与两个明确动作（执行/取消），不使用"确定/取消"这类泛称。

焦点与键盘：方案站点由主题提供跳过导航、`Tab` 顺序与目录深链；终端只依赖行缓冲输入，不实现自定义按键捕获，避免与宿主快捷键冲突。

### 9.5 Icons

方案站点与原型使用内联 SVG 图标，尺寸档位 16 / 20 / 24 px，线宽 1.5 px 为基准，颜色一律 `currentColor`，随主题变色；装饰性图标加 `aria-hidden="true"`，承载语义的图标配 `aria-label`。禁止用 emoji、符号字符或位图充当图标，也禁止用 emoji 表示状态与优先级——终端状态用 `[成功]`、`[失败]`、`[等待]`、`[需确认]` 文本标签，方案站点状态用 SVG 加文字。

不引入插图类资源：本产品的空态与错误态用"一句话 + 一个动作"表达，配一个 24 px 的状态图标即可；不使用位图，避免主题切换与语言切换时失真。

### 9.6 Motion

动效令牌：`--dur-fast: 120ms`、`--dur-base: 200ms`、`--dur-slow: 320ms`；曲线 `--ease-standard: cubic-bezier(0.2, 0, 0, 1)`、`--ease-enter: cubic-bezier(0.05, 0.7, 0.1, 1)`、`--ease-exit: cubic-bezier(0.4, 0, 1, 1)`。可用范围：折叠展开、抽屉进出、搜索面板淡入、按钮提交中、复制确认、进度刷新。禁止：整页位移、阻塞交互的动画、无降级分支的循环动画。

| 微交互 | 触发条件 | 变化属性 | 时长/曲线 | 可中断 | 减少动效偏好下的降级 |
|---|---|---|---|---|---|
| 章节折叠 | 点击章节标题 | 高度 0 与内容展开 | `--dur-base` / `--ease-standard` | 是（连点取最后一次） | 直接跳变，无过渡 |
| 抽屉进出 | 窄屏点击导航按钮 | 位移 + 遮罩透明度 | `--dur-base` / enter、exit | 是（`Esc`） | 直接显示/隐藏 |
| 搜索面板 | `/` 或点击搜索 | 透明度 0→1、上移 4 px | `--dur-fast` / enter | 是 | 直接显示 |
| 按钮提交中 | 提交上传/转存 | 文案切换为进行时 + 禁用 | `--dur-fast` | 否（请求不可中断） | 仅文案切换 |
| 复制确认 | 复制链接/命令 | 图标切换 + 文案"已复制"2 秒后复原 | `--dur-fast` | 是 | 仅文案切换，2 秒后复原 |
| 终端进度 | 大文件传输 | 已处理字节与百分比 | 刷新间隔 ≥ 200 ms | 是（`Ctrl+C`） | 每秒最多刷新 1 次；无动画时只输出阶段与最终结果 |
| 终端等待指示 | 长任务 | 旋转指示字符 | 80 ms/帧 | 是 | 改为每 5 秒输出一行"处理中，已等待 N 秒" |

反馈不得改变元素占位：加载态使用固定高度的骨架或占位文案，不得让表格行高跳动；动画只用于反馈"操作已被接收"，不承载业务状态——业务状态一律以文字表达。

### 9.7 Copy

| 场景 | 规则 | 示例 |
|---|---|---|
| 按钮 | 用动词加对象，不用"确定/提交" | `上传并覆盖`、`删除 3 项`、`转存到我的网盘` |
| 失败提示 | 事实 + 原因 + 下一步 | `提取码不正确，请检查后重试（错误码 13003）。` |
| 空态 | 说明用途 + 下一步 | `这个目录还是空的。可以先上传文件，或换一个目录看看。` |
| 筛选无结果 | 区分于空目录 | `没有符合条件的文件。清除筛选可以看全部 12 项。` |
| 需确认 | 对象 + 后果 + 两个动作 | `将删除 3 个文件（共 2.4 MB），删除后不可恢复。` |
| 成功 | 动作 + 实际落点 + 链接 | 已保存到：我的应用数据/bdpan/报告.pdf（附查看链接） |
| 等待 | 说明正在做什么 + 预计 | `首次读取需要格式转换，正在解析，通常 1–5 分钟。` |
| 提交态 | 只承诺已提交 | `转存任务已提交，完成后我会告诉你保存路径。` |

术语统一引用第 15 章：不得在页面里把"转存"写成"保存"、把"授权"写成"登录账号"。文案中的数字带单位（`2.4 MB`、`3 项`、`5 分钟`），时间使用本地时区，路径使用展示形式。

### 9.8 Accessibility

对比度：正文与背景至少 4.5:1，大字号（≥ 18.66 px 粗体或 ≥ 24 px）至少 3:1，边框与焦点指示至少 3:1；禁用态文本也需 4.5:1，若无法达到则不使用禁用态，改为可点击并给出原因。

焦点：可见焦点环为 2 px 实线 `--brand`、外偏移 2 px；不以 `outline: none` 移除焦点；对话框与抽屉打开时焦点移入、关闭时回到触发元素；终端不劫持焦点。

键盘：方案站点可仅用键盘完成"导航 → 章节 → 折叠 → 链接"全路径；折叠标题为原生可聚焦元素；搜索支持 `↑`/`↓` 选择结果、`Enter` 打开、`Esc` 关闭。

可访问名称：图标按钮必须有 `aria-label`（如"切换明暗主题"、"打开章节导航"）；表格必须有表头且表头与数据列对应；状态变化（加载完成、复制成功）通过 `aria-live="polite"` 播报，且播报文案与视觉文案一致。

非颜色提示：状态同时有文字；进度条带百分比文本；链接带下划线而非仅变色。屏幕阅读器优先：所有终端的结构化输出保证在 `--json` 下无颜色控制字符，纯文本模式下行首带语义标签。

### 9.9 Internationalization

目标语言：简体中文（`zh-CN`，默认）与英文（`en-US`）。文案长度按最长语言预留约 30% 余量；按钮最小宽度 96 px、最大 240 px，超出换行而不是截断；表格表头允许两行。

复数与性别：英文按键值区分 `one/other`（如 `1 file` / `3 files`），中文不区分复数；不使用带性别的代词，统一用"你/you"。

日期、时间、数字、货币：统一走一个格式化入口（`formatValue(kind, value, locale)`），日期为 `YYYY-MM-DD HH:mm`，数字千分位，容量按 1024 进制并带单位（`GiB`），货币仅用于会员入口页面，不在本产品内计算价格；相对时间（"3 分钟前"）只用于列表辅助列，悬停或聚焦时显示绝对时间。

字体回退与断行：英文使用无衬线栈，中文追加 `Microsoft YaHei`、`PingFang SC`、`Noto Sans CJK SC` 回退；中英混排时数字与英文单词不强制断行，长路径在 `/` 处优先断行；不使用两端对齐，避免中英混排出现大间隙。

布局不得依赖固定文案宽度：确认提示、错误块、表格单元格均按内容伸缩；终端摘要行的中文与英文版本各自独立成句，不做逐字直译。
