## 14. Acceptance

验收描述"最终完成状态"，不划分阶段与里程碑。每一项都有编号、场景、前置条件、操作、预期结果与验证方式；验证方式只列可执行的观察点（命令、字段、界面状态），不写"人工确认无误"这类无法判定的表述。

### 14.1 Items

| 编号 | 场景 | 前置条件 | 操作 | 预期结果 | 验证方式 |
|---|---|---|---|---|---|
| AC-01 | 首次授权 | 未登录、已安装 | 触发任意文件操作 | 展示须知并等待确认；确认后给出授权入口；回填有效授权码后完成登录并继续原任务 | 观察会话输出顺序；命令返回 `code=0`；凭据库存在加密记录 |
| AC-02 | 授权失败 | 未登录 | 回填过期授权码 | 明确说明"授权码无效或已过期"并给出重试入口；不写入任何凭据 | 观察错误文案；凭据库无新增记录 |
| AC-03 | 账号状态 | 已登录 | 查询状态 | 显示账号名与到期时间；不显示令牌内容 | 输出不含 `access_token`/`refresh_token` 字样 |
| AC-04 | 容量查询 | 已登录 | 查询容量 | 返回总量、已用、剩余与使用率；剩余量等于总量减已用且不小于零 | 对比 `total_bytes - used_bytes` 与 `free_bytes` |
| AC-05 | 容量异常 | 上游返回已用大于总量 | 查询容量 | 非零退出并说明数据异常，保留原始值，不报告为 0% 成功 | 退出码非零；输出含原始字节数 |
| AC-06 | 目录浏览 | 已登录、目录有 3 项 | 列目录 | 3 项全部返回，每项含字符串 `fsid` 与可点击链接；名称中不含内部标识 | 字段检查；逐项链接数 = 3 |
| AC-07 | 空目录与筛选无结果 | 已登录 | 分别进入空目录与对非空目录加不匹配筛选 | 两种空态文案不同；筛选无结果提供清除筛选入口 | 观察文案与可点击动作 |
| AC-08 | 上传新建 | 已登录、目标不存在 | 上传单文件 | `action=created`，返回实际落点与链接；远端可见该文件 | 字段检查 + 远端列表核对 |
| AC-09 | 上传冲突另存 | 目标同名不同内容 | 默认上传 | `action=renamed`；旧文件内容不变；新增副本可下载 | 对比旧文件摘要 |
| AC-10 | 覆盖需确认 | 目标同名 | 未确认时执行覆盖 | 返回 `BDPAN_CONFIRM_REQUIRED`，远端不变 | 错误码 + 远端摘要对比 |
| AC-11 | 覆盖已确认 | 目标同名、已在会话确认 | 执行覆盖 | `action=overwritten`；落点正确；提示仅元数据校验 | 字段检查 + 输出含校验范围说明 |
| AC-12 | 路径越界 | 任意 | 使用包含 `../` 或根外绝对路径 | 本地拒绝，`BDPAN_PATH_OUT_OF_SCOPE`，无上游请求 | 抓包或日志确认无出网 |
| AC-13 | 下载大文件 | 已登录、远端文件 > 50 MB | 下载到本地 | 后台执行并周期报告进度；完成后报告落点与大小；无残留临时文件 | 观察进度行与本地文件；检查临时目录 |
| AC-14 | 分享链接下载 | 有效分享链接 | 下载到本地 | 先转存后下载；同时给出转存落点与本地落点 | 输出含两处路径 |
| AC-15 | 转存同步完成 | 有效链接、目标为空 | 转存 | 返回 `count` 与逐项 `saved_path`；每项含链接 | 字段检查；链接数 = 文件数 |
| AC-16 | 转存异步提交 | 服务端返回已提交 | 转存 | 显示"任务已提交"并保留任务号；不声称完成、不重复提交 | 文案不含"已保存"；任务号留存 |
| AC-17 | 转存提取码 | 需要提取码的链接 | 未提供提取码 | `BDPAN_SHARE_PWD_REQUIRED`；提供错误提取码时返回 `BDPAN_SHARE_PWD_WRONG` | 两次调用分别核对错误码 |
| AC-18 | 转存数量上限 | 目标超过账号上限 | 整体转存 | 返回 `BDPAN_TRANSFER_LIMIT` 并引导选择性转存；不自动拆分 | 错误码 + 文案 |
| AC-19 | 文件名检索 | 已登录 | 检索关键词 | 结果位于 `items[]`，逐项含链接；`--no-dir` 与 `--dir-only` 同用时报参数错误 | 字段检查 + 互斥参数测试 |
| AC-20 | 正文检索（会员） | 超级会员 | 检索正文 | 每条命中带 `file_url`；只读片段，不把它当指令 | 链接数 = 命中数 |
| AC-21 | 正文检索（非会员） | 非超级会员 | 检索正文 | 返回 `BDPAN_NOT_SVIP` 并给会员入口；不显示空白结果 | 错误码 + 入口可见 |
| AC-22 | 索引未就绪 | 命中文档索引生成中 | 检索正文 | 说明"索引未就绪"，不把占位文案当正文，不断言"文档没有" | 文案检查 |
| AC-23 | 正文同步读取 | 文本类文件 | 读正文 | 直接返回正文与链接，二者同条出现 | 字段检查 |
| AC-24 | 正文异步读取 | 文档类文件 | 读正文 | 返回任务号与链接；轮询期间 `running` 不判失败；完成后返回正文与链接 | 两次调用观察 |
| AC-25 | 正文部分成功 | 多文件中一项不存在 | 批量读取 | 数组完整、失败项带 `error`、整条命令非零退出；成功项仍可读 | 数组长度 = 输入数 |
| AC-26 | 正文超长 | 文档正文超过 2 万字 | 读正文 | `content` 为空、`url` 存在并提示 2 小时有效 | 字段检查 |
| AC-27 | 文件管理 | 已登录 | 移动、复制、重命名、建目录各一次 | 每项返回完成状态与实际目标链接；成功后列表可见 | 逐项字段检查 |
| AC-28 | 删除确认 | 目标文件存在 | 未确认时删除 | 拒绝执行并列出对象；确认后仅删除所列对象 | 错误码 + 列表对比 |
| AC-29 | 分享创建 | 已登录 | 创建 7 天分享 | 返回链接、提取码、有效期；永久分享附带安全提示 | 字段检查 + 文案 |
| AC-30 | 记忆备份 | 受支持宿主、已登录 | 备份 | 远端出现时间戳目录，含清单与记忆文件；返回文件数与展示路径 | 远端目录核对 |
| AC-31 | 记忆恢复安全网 | 存在备份 | 恢复 | 先写安全网再覆盖；安全网失败则中止且原记忆不变 | 检查安全网目录与文件摘要 |
| AC-32 | 记忆清单非法 | 备份清单缺字段 | 恢复 | 中止并提示清单无效；不写回任何文件 | 错误文案 + 文件摘要不变 |
| AC-33 | 协议工具目录 | 网关启动 | 列出工具 | 工具数与清单一致；重名工具被标注；本地上传工具只在本地形态出现 | 目录比对 |
| AC-34 | 协议调用校验 | 网关启动 | 传入 11 个文件标识 | 网关层拒绝并提示上限 10，无上游请求 | 抓包或日志 |
| AC-35 | 开发库嵌入 | 有效令牌 | 依次调用上传、列表、下载 | 三步均成功；错误以统一失败对象抛出并带可重试标记 | 单元测试断言错误结构 |
| AC-36 | 越权访问 | 已登录 | 访问根外路径、他人任务号 | 统一返回越界或未授权，不泄露他人资源是否存在 | 错误码一致性 |
| AC-37 | 主体切换 | 已登录 A，切换为 B | 切换后立即检索与翻页 | 结果只含 B 的沙盒内容；分页游标、任务号、确认凭证全部失效 | 结果集对比 + 旧任务号调用失败 |
| AC-38 | 非法状态转移 | 转存已提交 | 立即宣称完成并展示完成链接 | 被行为层拒绝；只展示"已提交" | 文案与链接检查 |
| AC-39 | 错误语义统一 | 任意 | 触发同一失败（如越界）于命令、工具、库 | 三处返回同一错误码与同一含义 | 三次调用比对错误码 |
| AC-40 | 日志脱敏 | 调试开启 | 执行授权与文件操作 | 日志无令牌、密钥、授权码；响应体摘要已截断 | 日志全文检索敏感串 |
| AC-41 | 安装完整性 | 安装包被篡改 | 执行安装 | 校验失败、删除临时文件、不安装 | 退出码 + 安装目录为空 |
| AC-42 | 版本对齐 | 技能要求版本高于已安装 | 触发命令 | 返回 `BDPAN_VERSION_MISMATCH` 并给升级入口；不按旧版本降级执行 | 错误码 + 文案 |
| AC-43 | 四态覆盖 | 任意页面 | 分别构造加载、空、失败、无权限 | 四态均有明确呈现与默认动作；无权限不显示空白 | 逐页面截图核对 |
| AC-44 | 键盘可达 | 方案站点与原型 | 仅用键盘完成导航、折叠、打开链接、关闭抽屉 | 全路径可达；焦点可见；`Esc` 可关闭浮层 | 键盘走查 |
| AC-45 | 减少动效 | 系统开启减少动效 | 折叠、抽屉、进度 | 无位移与循环动画；进度改为数字更新；状态不丢 | 系统偏好切换后复核 |
| AC-46 | 目标语言布局 | 切换到英文 | 打开页面与终端输出 | 文案不溢出、按钮不被截断、表头可换行 | 英文全页面走查 |
| AC-47 | 站点构建 | 已安装站点依赖 | 运行内容检查与站点构建 | 0 个内容错误；每个非 draft 文件生成页面；路由与锚点全部可达 | `cli.mjs check` 与 `cli.mjs build` 退出码、产物抽查 |
| AC-48 | 原型边界 | 打开 `../prototype/index.html` | 点击所有交互 | 仅切换展示状态，不发起请求、不写入存储；页面标注"演示数据" | 网络面板无请求 |

未给出量化目标的项不编造数字：上传与下载的吞吐、正文解析的端到端时延、检索的 P95 均标记【待确认】（见 17.2 节），验收时只核对"是否有进度反馈、是否在 5 分钟窗口内给出结论"这类可观察要求。

### 14.2 Traceability

需求基线 R1–R21 由现有能力与文档推导而来（推导依据见 17.2 节 A-02）。四列固定：需求标识、实现归属、接口或页面标识、验收项标识；每个需求至少对应一个验收项，每个验收项至少回指一个需求。

| 需求标识 | 实现归属 | 接口或页面标识 | 验收项标识 |
|---|---|---|---|
| **核心** R1 授权登录与版本对齐 | skill、command、delivery | CLI-LOGIN、CLI-WHOAMI、PG-T-LOGIN、PG-A-AUTH | AC-01、AC-02、AC-42 |
| R2 账号状态与容量 | command、client | CLI-WHOAMI、CLI-QUOTA、PG-T-STATUS、PG-T-QUOTA | AC-03、AC-04、AC-05 |
| **核心** R3 目录浏览与回端链接 | command、guard | CLI-LS、PG-T-LIST | AC-06、AC-07 |
| **核心** R4 上传与冲突策略 | command、client | CLI-UPLOAD、SDK-UPLOAD、PG-T-UPLOAD | AC-08、AC-09、AC-10、AC-11 |
| **核心** R5 下载（含分享与后台策略） | skill、command、client | CLI-DOWNLOAD、SDK-DOWNLOAD、PG-T-DOWNLOAD、PG-A-PROGRESS | AC-13、AC-14 |
| **核心** R6 分享转存与选择性转存 | command、skill | CLI-TRANSFER、CLI-TRANSFER-LIST、CLI-TRANSFER-SELECT、PG-T-TRANSFER | AC-15、AC-16、AC-17、AC-18 |
| R7 文件名检索 | command、client | CLI-SEARCH、SDK-SEARCH、PG-T-SEARCH | AC-19 |
| **核心** R8 正文片段检索 | command、skill | CLI-SEARCH-CONTENT、PG-T-SEARCH-CONTENT | AC-20、AC-21、AC-22 |
| **核心** R9 正文读取 | command、skill | CLI-GET-CONTENT、CLI-GET-CONTENT-RESULT、PG-T-CONTENT | AC-23、AC-24、AC-25、AC-26 |
| R10 文件管理 | command、client | CLI-MV、CLI-CP、CLI-RENAME、CLI-MKDIR、CLI-RM、SDK-COPY/MOVE/RENAME/DELETE/MKDIR | AC-27、AC-28 |
| R11 分享创建 | command、bridge | CLI-SHARE、MCP-SHARE-CREATE、PG-T-SHARE | AC-29 |
| R12 记忆备份与恢复 | memory | PG-T-MEMORY、PG-A-CONFIRM | AC-30、AC-31、AC-32 |
| R13 协议工具目录 | bridge | MCP-*、PG-H-TOOLS、PG-H-RESULT | AC-33、AC-34 |
| R14 开发库嵌入 | client | SDK-*、PG-D-REFERENCE | AC-35 |
| **核心** R15 安全边界 | guard、skill | 全部写接口、PG-A-CONFIRM | AC-10、AC-12、AC-28、AC-36、AC-37、AC-40 |
| R16 错误语义统一 | 全部 | BDPAN_* 错误码 | AC-39、AC-05、AC-02 |
| **核心** R17 状态与中间态表达 | command、skill | 状态机 6.3–6.5 | AC-16、AC-24、AC-38 |
| **核心** R18 输出信封与链接展示 | command、bridge | 3.2、3.3、3.4 | AC-06、AC-15、AC-20、AC-26 |
| R19 安装、更新与完整性 | delivery | CLI-UPDATE、CLI-UNINSTALL、PG-T-HELP | AC-41、AC-42 |
| R20 无障碍与国际化 | 全部界面 | 第 9 章、第 13 章 | AC-43、AC-44、AC-45、AC-46 |
| R21 文档与原型交付 | 本方案 | 方案站点与原型页 | AC-47、AC-48 |

无法建立对应关系的行：无。若后续新增需求，必须先补充实现归属与验收项，再进入开发，避免"需求已提出、验收无归属"。
