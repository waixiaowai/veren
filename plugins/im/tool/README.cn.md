# @veren/im-tool

面向模型的 `im_*` 工具族与 `im-collaboration` 技能，架在重设计后的各家族面之上
（会话、协调、回合、目录、采集、记忆、绑定）。

## 何时使用

当 IM 房间会话中的智能体需要对协作工作区做事时使用本包：穿写入闸门向自己的房间发送、
读房间与时间线、浏览人员目录、上报自我介绍、查看采集审计、维护自己的持久记忆。调用方
归属来自回合服务的会话映射——工具调用永远以它自己的智能体参与者身份在它自己的房间里
行动；模型绝不指名房间。在任何 im 托管会话之外，所有房间作用域的工具都以 `IM_NOT_FOUND`
拒绝。

## 工具

| 工具 | 效果 |
|---|---|
| `im_bind` / `im_unbind` | 账号授权生命周期（绝不触碰房间） |
| `im_send` | 向调用方自己的房间写入一道闸门后的回复；`held:true` 是指引（改写或安静），不是错误 |
| `im_rooms` / `im_read` | 只读定向；`im_read` 只推进已读游标，绝不推进已见水位 |
| `im_people` / `im_person_save` | 目录浏览与创建/补充 |
| `im_person_report` | 记录一条未核实自述并收尾采集问题 |
| `im_intake` | 陌生人询问的开关、计数与审计 |
| `im_remember` / `im_recall` | 按智能体的持久记忆（置顶优先，其余按近期） |

## 技能

`im-collaboration` 承载机制所强制的纪律：回复契约（回合文本就是房间消息）、HELD 语义
（改写或安静，绝不复读）、安静纪律与记忆礼仪。
