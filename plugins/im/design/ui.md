## 23. Interface Specification

界面规范约束五个界面壳共用的视觉与交互事实：颜色、字体、间距、动效、文案、无障碍、国际化、图标与主题。规范只定义令牌与规则，不规定具体页面长什么样；页面组装与四态见 [产品端与页面](./product/)，组件分层见后续组件章。所有取值以现有产品观察值为基线，凡属方案新增的规则都写明"目标"，不把目标当成已实现。

### 23.1 Color

颜色以 CSS 变量承载，变量值是空格分隔的 RGB 三元组，Tailwind 通过透明度修饰符绑定；亮暗两套只替换变量，不替换类名。品牌色 sky 负责选中、链接与强调，coral 负责错误，gold 负责提醒，whisper 负责私聊与旁听，ink 六级负责文本，paper 与 cloud 负责页面与卡片。

| 令牌 | 亮色 | 暗色 | 语义与用法 |
| --- | --- | --- | --- |
| sky | #00A8F0 | #61AFEF | 品牌主色、选中态、可点击强调 |
| sky-deep | #0078C8 | #528BFF | 悬停与按下，焦点环外圈 |
| sky-ink | #003B6F | #ABB2BF | 浅底上的可读强调文本 |
| sky-50 至 sky-300 | #F2FAFE / #E1F3FD / #C2E6FB / #8FD3F7 | #2C313C / #313640 / #3E4451 / #4B5263 | 由浅到深的底色层级 |
| sky-glow | #4FC2F4 | #61AFEF | 光晕、装饰渐变，不承载信息 |
| coral | #FF7A6B | #E06C75 | 错误、危险操作、等待状态 |
| coral-soft | #FFD9D2 | #3D2A2E | 错误卡片与提示底色 |

语义扩展令牌由基础色派生，页面不得直接写十六进制值：

| 扩展令牌 | 取值来源 | 用途 |
| --- | --- | --- |
| chrome 系列 | paper 与 cloud 的派生 | 标题栏、导航栏、面板壳；暗色收敛为扁平 paper |
| modal-scrim | ink-900 的 40% | 模态遮罩；暗色同义重映射 |

| chat-wash 与 whispers-wash | sky 与 whisper 的低透明度 | 会话与私聊的极淡背景 |
| doc 系列 15 个 | paper、ink、cloud | 文档画布、批注、提及、代码块 |
| board 与 ship 系列 | paper、cloud、gold、coral | 看板卡片、交付画布与证据面 |
| error-card 系列 | coral 与 coral-soft | 行内错误卡片 |
| unread-fresh | sky 与 sky-50 | 新消息标记与未读底 |
| email-backdrop 与 email-muted | ink 与 paper | 邮件抽屉背景与引用文本 |

对比度要求按下表执行，状态色与品牌色不得绕过：

| 用途 | 下限 | 说明 |
| --- | --- | --- |
| 正文与正文级链接 | 4.5:1 | 所有正文级文本，包括 12 px 次要文本 |
| 大字号标题 | 3:1 | 不小于 24 px，或不小于 18.66 px 且加粗 |
| 图标、输入边框、选中标记 | 3:1 | 与相邻底色比较，不能只靠位置区分 |
| 焦点环 | 3:1 | 与环内外两侧底色都要可辨 |
| 禁用态文本 | 不适用 | 不承担信息，但不得低到无法辨认 |

已知风险与约束：sky 与 paper 的对比不足以承载正文，只能作填充、描边与选中底；需要文字时改用 ink 或 sky-ink。coral 与 gold 在浅底上同样不能直接写正文，错误与提醒文本分别使用 coral-deep 与 gold-deep，并在实现时以实测值复核；任何未达到 4.5:1 的组合不得进入正文层。

### 23.2 Typography

字体族与回退固定为四条，不允许页面自造：

| 令牌 | 字体族与回退 | 用途 |
| --- | --- | --- |
| display | Manrope、system-ui、Segoe UI、sans-serif | 标题、标签、品牌语气 |
| body | Manrope、system-ui、Segoe UI、sans-serif | 正文、按钮、表单 |
| mono | JetBrains Mono、ui-monospace、SFMono-Regular、Menlo、monospace | 代码、序号、时间戳 |
| doc | Fraunces、Georgia、serif | 文档编辑器正文；Fraunces 当前未加载，实际回退 Georgia，是否加载待确认 |

原生壳覆盖全部字体为 `-apple-system` 与 SF Pro，并关闭连字特性；这是"像原生"收益最高的一条规则，网页壳不跟随。正文启用 `ss01` 与 `cv11` 两个字形特性，仅对拉丁字符生效，原生壳关闭。

字号观察值从 9 px 到 32 px，共二十余档；方案归并为八档，9 至 36 作为允许区间，36 只作上限预留，不新增档位：

| 观察值 | 归并令牌 | 字号与行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| 9 至 10 | caption | 10 / 14 | 500 | 金属标签、角标、时间 |
| 11 至 12 | meta | 12 / 17 | 500 | 次要信息、导航徽标、按钮小号 |
| 13 至 13.5 | body | 13 / 20 | 400 | 正文、消息、表单默认 |
| 14 至 15 | body-lg | 14 / 21 | 400 | 长消息、文档摘要 |
| 16 至 17 | title-sm | 16 / 24 | 600 | 卡片标题、弹层标题 |
| 18 至 20 | title | 20 / 28 | 600 | 区块标题、页面副标题 |
| 22 至 26 | display-sm | 26 / 32 | 600 | 移动端页面主标题 |
| 28 至 32 | display | 30 / 38 | 600 | 桌面端页面主标题 |

字重只使用 400、500、600、700 四档；300 与 800 仅保留在字体文件中，不进入界面。标题字距 `-0.012em`，正文为 0。行高比例：标题 1.2 至 1.3，正文 1.5，长文本 1.6 至 1.65，代码 1.6。

长文本规则：正文与消息允许任意换行，URL 与长标识使用 `overflow-wrap: anywhere`；列表预览最多两行截断，标题与名称单行省略并保留完整文本作为可访问名称；代码块横向滚动，不折行；中英混排按 CJK 断行规则，禁止在数字与单位、英文单词内部断行。

### 23.3 Spacing and Layout

间距以 4 px 为基准，按信息亲疏分级，不引入第二套尺度：

| 级别 | 取值 | 用途 |
| --- | --- | --- |
| 控件内 | 4 至 8 | 图标与文字、输入框内边距 |
| 相关字段 | 12 | 同一表单的相邻字段 |
| 组件组 | 16 至 24 | 卡片内区块、列表分组 |
| 页面区块 | 32 至 48 | 页面级分区与标题前留白 |

固定几何是壳的骨架，页面不得覆盖：

| 区域 | 取值 | 说明 |
| --- | --- | --- |
| 桌面标题栏 | 44 px | 含原生窗口按钮留白与拖拽区 |
| 桌面导航栏 | 72 px | 图标加标签，选中态用底色与左侧标记 |
| 会话侧栏 | 320 px，可拖至 240 至 520 px | 宽度写入本地存储，重开后恢复 |
| 右栏 | 420 px，文档与看板用 clamp 至 640 px | 同一时刻只允许一个右栏面板 |
| 文档列表 | 280 px | 固定，不参与拖拽 |
| 浏览器窗口卡片 | 最大 1480 px，四周留 24 px | 仅浏览器壳，Electron 铺满 |

断点分三组，互不替代：

| 断点 | 宽度 | 行为 |
| --- | --- | --- |
| 应用断点 | 768 px | 小于则进入移动布局；原生壳强制移动，不受宽度影响 |
| Tailwind 默认 | 640 / 768 / 1024 / 1280 / 1536 | 仅用于局部响应式，不改变壳 |
| 后台 | 900 / 720 / 480 | 900 侧栏转抽屉，720 网格折叠，480 紧凑行 |

栅格规则：主应用采用"固定栏宽加弹性内容"，不引入通用十二栅格；后台表格按内容列宽自适应，在 720 px 以下折叠为两列。弹层宽度取内容宽度并设上下限，最小 320 px，最大不超过视口减 48 px；高度不超过视口减 96 px，超出时内部滚动。

滚动容器规则：每个面板独立滚动，页面本身不滚动；移动端固定 100dvh，只有列表与转写区滚动。嵌套滚动只允许出现在弹层内部，且外层不再滚动。滚动位置在切换会话、关闭右栏、前进后退时保持；新消息到达时只有"已在底部"才自动跟随，否则显示回到最新按钮。PageUp、PageDown、Home、End 在可滚动区域内必须生效。

### 23.4 Motion

动效只做反馈与空间关系提示，不承载业务状态，也不阻塞交互。令牌如下：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| instant | 80 ms | 按压反馈、勾选、复制确认 |
| fast | 150 ms | 悬停、聚焦、徽标、颜色过渡 |
| base | 200 ms | 弹层、展开折叠、淡入 |
| slow | 300 ms | 抽屉、侧栏、页面级面板 |
| standard | cubic-bezier(0.4, 0, 0.2, 1) | 默认双向过渡 |
| enter | cubic-bezier(0.2, 0.8, 0.2, 1) | 进入、展开、上浮 |
| leave | cubic-bezier(0.4, 0, 1, 1) | 离开、收起；目标规则，现状多用默认曲线 |
| spring | stiffness 320、damping 38、mass 1 | 移动端压栈与弹层，临界阻尼无回弹 |
| tab-fade | 140 ms | 移动端标签切换 |
| press | 80 ms，缩放 0.97 | 移动端按压，随手指按下发生 |

命名动画只允许下表这些，新增必须复用或登记：

| 动画 | 值 | 用途 |
| --- | --- | --- |
| pulse-soft | 1.5 s 循环 | 执行中状态点 |
| rise | 0.5 s enter | 空态插画与提示上浮 |
| drift | 40 s 循环 | 浏览器壳背景光斑，仅装饰 |
| bounce-dot | 1.2 s 循环 | 正在输入三点 |
| shine | 2 s 循环 | 骨架屏扫光 |
| fade-in | 200 ms | 通用淡入 |
| slide-in-right | 220 ms enter | 右栏与全屏层进入 |
| toast-drain | 12 s 线性 | 通知自动关闭进度，悬停暂停 |

微交互的可用范围：悬停与聚焦只改颜色、阴影与描边；按压只改缩放与透明度；展开折叠改高度与透明度；提交中只改按钮内状态，不移动布局；复制确认在原地替换文案 1.2 s；拖拽抬起只改阴影与轻微缩放。微交互的位移不得超过 8 px，页面与弹层的进入位移不受此限；任何动画不得阻止点击、输入或滚动；同一区域同时触发的过渡必须共用同一时长与曲线。

减少动态效果偏好的降级：现状只覆盖背景光斑、部分装饰动画与反应动画，移动端弹簧、标签淡入与工件弹层仍在播放，属于覆盖不足。目标规则是统一降级：开启偏好后，所有位移动画取消，弹簧与视差改为不超过 120 ms 的淡入或直接切换；循环装饰动画暂停在首帧；通知进度条保留但去掉滑入滑出；焦点环、状态色与文案提示不降级。降级必须由同一入口判定，不允许组件各自读取媒体查询。

### 23.5 Microcopy

文案语气：温暖、第二人称、少用感叹号；中文用全角标点与破折号，产品术语保持统一，不中英混写同一概念。按钮一律以动词开头，写清对象与结果，不用"确定""提交""是"这类泛称；危险按钮直接写后果，如"删除文档""停用账号"。

错误提示固定三段：发生了什么、为什么、下一步。第一段陈述事实，第二段给可理解的原因，第三段给可执行动作；技术细节与状态码放在次要行，不进入主句。

```text
标题  消息没有发出去
原因  连接中断，这条消息还留在输入框
下一步  检查网络后重试，或先复制内容
```

空态写用途与下一步，不写"暂无数据"；确认弹窗写对象、后果与不可逆性；成功反馈就近显示，表单成功不用全局通知，后台任务成功才用通知栈。四类文案的结构如下：

| 类型 | 结构 | 示例 |
| --- | --- | --- |
| 空态 | 这是什么加为什么空加下一步 | 还没有文档。新建一篇，智能体也能一起写 |
| 确认 | 动作加对象加后果 | 删除这篇文档？协作者将立即失去访问 |
| 成功 | 结果加范围加可撤销性 | 已邀请 3 人，邀请链接 7 天后失效 |
| 失败 | 事实加原因加动作 | 文件超过 25 MB，请压缩后重试 |

真实双语文案作为语气锚点，新增文案向它们对齐：

| 键 | 英文 | 简体中文 |
| --- | --- | --- |
| common.titlebarTagline | — where agent teams gather | —— 智能体团队的汇合地 |
| common.languageSub | this device only · applies immediately | 仅本设备 · 立即生效 |
| onboard.waiting | Waiting for your computer to connect… | 等待你的计算机连接… |
| onboard.rotate | Pairing code leaked? Generate a new one | 配对码可能泄露？重新生成 |
| viewBoundary.hitASnag | {name} hit a snag. | {name}遇到了一点问题。 |
| chat.slashPollHint | Start a poll — agents and humans can both vote | 发起一次投票，智能体和人人都能参与 |

术语按统一命名清单引用，不在页面另造同义词：智能体、人类成员、工作区、会话、房间、私聊、旁听、看板、卡片、日程、文档、交付、宿主、计算机、配对码、回合、唤醒。英文界面使用 agent、workspace、conversation、group、whisper、board、card、event、document、shipping、host、computer、pairing code、turn；"机器人""项目组""频道"不作为同义词出现。

### 23.6 Accessibility

无障碍的底线是：关键路径可以只用键盘完成，状态变化不只靠颜色，错误能被辅助技术读到。

| 项 | 规则 |
| --- | --- |
| 对比度 | 正文 4.5:1，大字号与图标 3:1，焦点环 3:1 |
| 焦点可见 | `:focus-visible` 显示 2 px 外环加 2 px 偏移，颜色用 sky-deep；不得用 `outline: none` 除非同时提供等效替代 |
| 焦点顺序 | 跟随 DOM 顺序，打开浮层后焦点进入浮层，关闭后回到触发元素 |
| 跳过导航 | 首个 Tab 停靠点是"跳到主内容"，直接聚焦主面板；现状未见实现，属目标规则 |
| 图标按钮 | 必须有可访问名称，语义图标给 `aria-label` 与 `title`，纯装饰图标标记 `aria-hidden` |
| 表单错误 | 字段加 `aria-invalid`，错误文本用 `aria-describedby` 关联，提交失败时以 `role="alert"` 播报摘要 |
| 状态变化 | 用文案加图形加颜色三重表达；通知与保存结果用礼貌播报，不打断输入 |

键盘快捷键全表如下，作用域与动作固定，新增快捷键必须登记并避开输入法组合键：

| 快捷键 | 作用域 | 动作 |
| --- | --- | --- |
| ⌘K 或 Ctrl+K | 桌面会话 | 聚焦侧栏搜索 |
| ⌘⇧O 或 Ctrl+Shift+O | 开发构建，任意壳 | 切换配对引导预览 |
| Enter | 输入区 | 发送；输入法组合期间不发送 |
| Shift+Enter | 输入区 | 换行 |
| Tab | 提及、斜杠、表情选择器 | 接受当前高亮项 |
| ↑ 与 ↓ | 选择器、菜单、列表 | 移动高亮 |
| Escape | 浮层、选择器、内联编辑、图片查看器 | 关闭最上层并归还焦点 |
| Home 与 End | 下拉选择器 | 跳到首项或末项 |
| ⌘Enter 或 Ctrl+Enter | 看板多行字段 | 提交 |
| Android 返回 | 移动端 | 先弹一层，未被处理时才退出应用 |

当前缺口必须写清：没有焦点陷阱，也没有 `inert`；只有少数浮层声明 `aria-modal`，多数模态只靠 Escape 与遮罩点击关闭。目标规则是所有模态浮层统一焦点陷阱、`aria-modal="true"`、背景 `inert`、关闭后焦点归还；非模态浮层不设陷阱，但 Escape 关闭且归还焦点。该差异记为待确认项，需与组件章一起落地。

输入法保护：所有以 Enter 提交的输入区必须判断组合状态，组合期间不触发发送、不关闭选择器；中文、日文、韩文输入法的候选确认键与提交键不得冲突。粘贴、拖放与软键盘退格同样走统一判定，不各自实现。

### 23.7 Internationalization

目标语种只有两个：英文为源语言，简体中文为全量镜像，各 1632 个键，扁平点号键空间按区域前缀分约四十组。

| 项 | 现状 | 规则 |
| --- | --- | --- |
| 语种 | en 与 zh-CN | 不新增第三语种；新增须先补全键空间 |
| 键结构 | 扁平点号，区域前缀 | 键名描述用途，不复用同义键；拼错键由类型检查拦截 |
| 查找 | 当前语种到英文再到键名 | 缺失回退英文，不显示空白 |
| 插值 | 仅 `{name}` 形式 | 未知变量保留字面量，让错误可见；禁止在文案里拼 HTML |
| 复数 | 无复数引擎 | 用平行键表达，如单数与复数各一键；不按数量做字符串拼接 |
| 日期时间 | 约二十处直接调用本地化格式 | 目标统一走一个格式化入口，按语种与时区输出；相对时间用同一个助手 |
| 数字与货币 | 无统一入口 | 目标统一用区域格式化，不在文案里写死分隔符 |
| 长度预留 | 无强制 | 按最长语言预留三成；按钮设最小宽度，超长换行或截断并保留完整名称 |

字体回退与断行：拉丁用 Manrope，中文回退到系统无衬线；中英混排不在词内断行，标点避头尾；按钮与表头不得依赖固定文案宽度，最小宽度按 44 px 命中区，最大宽度由容器决定。CJK 文案通常比英文短，布局以英文长度做下限校验，防止中文溢出被掩盖。

RTL 不适用：现有两语种均为从左到右书写，代码没有 `dir` 属性、没有逻辑属性、也没有 `rtl:` 变体；引入阿拉伯语或希伯来语需要重做布局与图标方向，不在本期范围。该判断不是"以后再补一行 CSS"就能解决，须在新增语种时单独立项。

### 23.8 Icons Images Media

图标一律使用手写 SVG，不使用图标字体、位图或 emoji 冒充图标。统一规格：24 视框、`fill` 为 `none`、`stroke` 为 `currentColor`、线宽 1.5、圆头圆角连接；尺寸档位 16、20、24、28，激活标签可加粗到 2，但不得改变视框。图标按钮的命中区不小于 32 px，移动端不小于 44 px。

装饰性图标对辅助技术隐藏；承载语义的图标给可访问名称，名称描述动作而不是图形。图标与文字同时出现时，图标隐藏以避免重复播报。空态与错误插画同样使用 SVG，随主题换色，不引入无法随语言与主题变化的位图。

图片分三类：内容图（消息附件、文档插图）、头像、装饰背景。内容图保留原始宽高比，最大宽度为容器宽度，点击进入查看器；替代文本由上传者填写，缺省时用文件名并说明"图片"；纯装饰背景与相邻文字已说明信息的头像使用空替代文本。首屏图片优先加载，折叠线以下懒加载；签名地址失效时就地刷新一次，仍失败则显示占位与"重新加载"。

视频与音频不适用：当前界面没有播放器、没有媒体元素，提示音由 Web Audio 合成两音铃，不依赖音频文件；因此自动播放、字幕、封面帧与控制条规则没有适用对象。若未来加入语音消息，须另行定义媒体规范，不能沿用本节。

自定义滚动条不适用：现状使用系统滚动条，不做全局美化；只规定局部容器保留可见滚动条、不隐藏滚动条、不因自定义宽度造成布局跳动。需要细滚动条时按平台原生表现，不引入第三方滚动条库。

### 23.9 Themes

主题只有亮与暗两套，暗色按 One Dark Pro 的色相映射，不逐页面手调。映射关系如下：

| 语义 | 亮色 | 暗色 | 映射依据 |
| --- | --- | --- | --- |
| 页面底 | paper #FAFCFE | #21252B | One Dark Pro 背景 |
| 卡片与浮层 | cloud #FFFFFF | #282C34 | 比页面底亮一级 |
| 正文 | ink-900 #0A1B2E | #ABB2BF | 暗色正文统一为前景灰 |
| 次要文本 | ink-500 #5B7186 | ink-700 #9DA5B4 | 提高暗底可读性，仍满足正文下限 |
| 边框与分隔 | ink-100 #E5ECF2 | #3E4451 | 低对比但不消失 |
| 强调 | sky #00A8F0 | #61AFEF | 品牌色提亮 |
| 错误 | coral #FF7A6B | #E06C75 | 色相保持，按暗色前景重取 |
| 提醒 | gold #F4B740 | #E5C07B | 色相保持，按暗色前景重取 |
| 私聊 | whisper #7B6CB0 | #C678DD | 紫系提亮 |
| 五个状态 | 见 23.1 | 见 23.1 | 按暗色前景重新取色，色相保持 |

优先级与时机：手动选择覆盖系统偏好，系统偏好覆盖默认亮色；首次启动读取本地外观设置，没有则跟随系统。切换在首帧前完成：内联脚本在样式表之前给根元素加暗色类，避免先亮后暗的闪烁。切换时同步更新浏览器主题色、桌面主进程外观与跨窗口存储事件，通知面板据此跟随。

持久化：外观选择存本地，键为 `cumora.appearance`，值为跟随系统、亮、暗三态；不写服务端，不跨设备同步。原生壳同时更新状态栏背景与图标风格，暗色用 `#21252B`、亮色用 `#FAFCFE`；通知面板透明背景不参与配色，但其文字与描边必须随主题切换。

切换过程中不得出现整页闪烁、白底黑字跳变或对比度不达标的中间态；首帧渲染不做颜色过渡，稳定后才允许 150 ms 的颜色过渡。用户在同一秒内连续切换时只应用最后一次，避免中间态叠加。
